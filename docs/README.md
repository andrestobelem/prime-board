# Documentación

Esta carpeta contiene la documentación del proyecto: especificaciones, relevamientos, auditorías, investigaciones y decisiones.

- `relevamiento-linear.md` — inventario de funcionalidades de Linear.
- `alcance-mvp.md` — alcance histórico del MVP y decisiones estructurales.
- `specs/mvp.md` — especificación técnica del MVP.
- `guia-agentes.md` — operación de prime-board mediante GraphQL, CLI, MCP y webhooks.
- `investigacion-tickets-en-repo.md` — uso del repositorio como fuente de verdad de los tickets y estado del contrato vigente.
- `extensiones-prime-agent.md` — uso de la extensión `question` para preguntas interactivas.
- `audits/linear-actual-diferencias.md` — comparación canónica con Linear actual y decisión multi-workspace (PRB-421).
- `audits/linear-modelo-datos.md` — auditoría del modelo de datos y sus relaciones frente a Linear (PRB-377).
- `audits/linear-paridad-graphql.md` — auditoría de paridad de la API GraphQL frente a Linear (PRB-396).
- `audits/linear-paridad-visual-usabilidad.md` — auditoría visual y de usabilidad frente a Linear (PRB-278).
- `research/linear-settings-parity.md` — snapshot histórico de paridad de Settings.
- `adr/0017-multi-workspace-compartido.md` — decisión vigente para varios Workspaces aislados en una DB/proceso.
- `research/sqlite-postgresql-podman.md` — investigación de la migración de SQLite a PostgreSQL con Podman (PRB-410).
- `research/prime-board-como-extension-prime-agent.md` — investigación del empaquetado de prime-board como package/extensión de Prime Agent (PRB-422).
- `agents/` — documentación que consumen las skills de `.agents/skills/`: tracker de Issues, estados de triage y estructura de la documentación del dominio.
