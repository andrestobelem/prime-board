# CLI: resolver project y milestone por nombre sin colisiones

Created by admin.

## Hallazgo reproducible

`pb issue update` anuncia `--project ID|NAME` y `--milestone ID|NAME`, pero envía nombres raw como IDs. `pb issue list`/update además resuelven homónimos con `.find` y pueden filtrar o mutar la entidad incorrecta.

## Comportamiento esperado

Resolver referencias por nombre antes de mutar/filtrar, usar el proyecto del issue para milestones y rechazar nombres ambiguos.

## Criterios de aceptación

- CLI resuelve project/milestone por UUID o nombre.
- Milestone se resuelve dentro del proyecto actual cuando aplica.
- Homónimos producen error explícito.
- Regresiones CLI.
