# UI: ampliar filtros y display options de las vistas

Created by admin.

## Contexto
La API ya soporta filtros por project, milestone, cycle, parent, creator, `unblocked` y composición `and/or`, pero la UI de team solo ofrece search, state, assignee, priority y label. Linear concentra filtros, layout, grouping, ordering y propiedades visibles en Display options.

## Evidencia
- `apps/web/src/issue-filter.ts` define solo cinco campos de draft.
- `apps/web/src/components/IssueFilterToolbar.tsx` muestra solo esos cinco filtros.
- `apps/web/src/App.tsx` persiste únicamente `groupBy` y ofrece un `select` simple.
- `packages/schema/src/sdl.ts` expone comparadores y `IssueOrder`.

## Comportamiento esperado
Las vistas deben permitir construir colas reproducibles con los campos que ya entiende la API y cambiar list/board/group/order/display properties desde un punto único.

## Criterios de aceptación
- [ ] Exponer project, milestone, cycle, parent, creator y unblocked; documentar si AND/OR se reserva para una edición avanzada.
- [ ] Unificar layout list/board, grouping y ordering bajo Display options.
- [ ] Permitir configurar propiedades visibles y grupos vacíos donde aplique.
- [ ] Persistir preferencias por actor/vista sin mezclar scopes.
- [ ] Mantener URL/deep-link y estados loading/error/empty.
