# UI TeamSettings: aceptar 0 para deshabilitar períodos de automation

Created by admin.

## Hallazgo

`TeamSettingsView` declara `min="0"` para los campos de período de las automations, pero su handler `onBlur` rechaza `value <= 0`. La API interpreta `0` como una forma válida de deshabilitar el período.

## Comportamiento actual

La UI permite escribir 0 por el atributo HTML, pero lo rechaza al perder foco o no lo normaliza de forma coherente con la API. Esto deja una divergencia entre contrato de API y configuración visible.

## Comportamiento esperado

La UI debe aceptar el valor 0 si representa «deshabilitado», enviar una representación canónica (`0` o `null`) y mantener la misma semántica que la API. Los valores negativos deben seguir siendo inválidos.

## Criterios de aceptación

- El campo de período acepta 0 y muestra la configuración deshabilitada.
- El payload UI/API usa una representación canónica documentada.
- Los valores negativos y valores no numéricos se rechazan.
- Hay una regresión de UI o integración para el caso 0.

## Trazabilidad

Hallazgo detectado durante PRB-383 antes de modificar la validación de `TeamSettingsView`.
