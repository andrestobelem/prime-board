# Integrations: completar Webhooks con resourceTypes y permisos admin

Created by admin.

## Alcance
Completar el contrato de Webhooks de PRB-387 sin reimplementar el despacho. El dispatcher y la entrega async de PRB-444, incluida la corrección de identificadores de PRB-581, son seams existentes y deben permanecer como una única implementación.

- Añadir selección `resourceTypes` al registro y al filtro de entregas.
- Conservar límites por `teamId` y validar cada referencia dentro del Workspace efectivo.
- Exigir permisos de Workspace admin para crear, listar y administrar webhooks; no permitir bypass mediante owner, API key limitada ni backend PostgreSQL.
- Mantener HMAC-SHA256 sobre los bytes exactos del body enviado. La firma se calcula antes de que el receptor parsee JSON.
- Mantener secreto de creación de una sola lectura. No exponer secretos en mappers, exports, logs o fixtures.

## Criterios de aceptación
- [ ] GraphQL, persistencia SQLite/PostgreSQL y clientes solo aceptan `resourceTypes` válidos, normalizados y persistidos sin mezclar Workspaces.
- [ ] Un webhook limitado por Team o recurso solo recibe eventos que corresponden a ese Team/recurso; un webhook sin límite no cruza el Workspace efectivo.
- [ ] Actor miembro, API key sin `admin`, Team ajeno y referencia cross-Workspace reciben un error estable. Admin puede crear, listar, borrar y gestionar.
- [ ] Regresión verifica HMAC con body no canónico (espacios/orden/saltos), y falla al reserializar o cambiar bytes.
- [ ] Regresiones focales no duplican ni modifican `WebhookDispatcher` más allá del filtro necesario; cubren SQLite y el seam `Persistence` de PostgreSQL.
- [ ] `bun run typecheck`, Prettier y `git diff --check` pasan. No hay secretos en evidencia.

## Seam y límites
Usar `WebhookEventSink`/`WebhookDispatcher` ya integrado por PRB-444. No crear otro dispatcher ni alterar su ciclo de reintentos. Validar aislamiento con `context.workspace.workspaceId` y las consultas de cada backend. PRB-581 queda como corrección de la carga PostgreSQL de eventos; no se duplica.
