# Auth: impedir spoofing de autoría y fechas en imports desde mutations públicas

Created by admin.

## Hallazgo reproducible

Un actor con membership en el team puede atribuir a otro actor y fechar en el pasado sus propias escrituras usando campos documentados como “imports”:

1. Crear `spoof-agent` y darle membership `MEMBER` en `PB`.
2. Autenticar con su API key y ejecutar:
   `issueCreate(input: { teamKey: "PB", title: "spoofed", number: 9999, creatorId: <adminId>, createdAt: "2020-01-01T00:00:00.000Z" })`. La mutación permite además elegir `number` y alterar el contador del team.
3. La mutación responde éxito y el issue muestra `creator: admin`, `createdAt: 2020-01-01` y `activity[0].actor: admin`, aunque la API key pertenece a `spoof-agent`.
4. Ejecutar `commentCreate(input: { issueId: "PB-1", body: "forged", authorId: <adminId>, createdAt: "2020-01-02T00:00:00.000Z" })`: el comentario también aparece como creado por `admin` y con esa fecha.

Evidencia: `apps/server/src/graphql/issue-resolvers.ts:202,259` reenvía los inputs; `apps/server/src/domain/issues.ts:153-155` y `apps/server/src/domain/comments.ts:38` aceptan `creatorId/authorId` y `createdAt`. El schema los describe como campos para imports, pero no existe una ruta de importación confiable ni una autorización especial.

## Comportamiento esperado

La identidad y la fecha de una escritura normal deben derivarse de la API key y del servidor. Los campos de autoría/fecha históricos deben estar restringidos a una ruta de importación confiable o a una política explícita de admin, sin permitir que un actor regular falsifique auditoría, inbox o actividad.

## Criterios de aceptación

- Una mutation pública no permite spoofear `creatorId`, `authorId`, `number` ni fechas históricas con una API key regular.
- La ruta de importación conserva autoría y fechas legítimas sin perder funcionalidad.
- La actividad, comentarios, webhooks e inbox atribuyen al actor autenticado en escrituras normales.
- Agregar regresiones para actor regular, admin/import y fechas inválidas.
