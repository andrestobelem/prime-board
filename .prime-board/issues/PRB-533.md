# My issues: corregir el modo Subscribed

Created by admin.

## Objetivo
Evitar que My issues presente como suscripción una consulta que actualmente devuelve Issues creadas o asignadas.

## Evidencia
- `apps/web/src/views/MyIssuesView.tsx` define el modo `subscribed` como `assignee OR creator`.
- `packages/schema/src/sdl.ts` no expone `subscriber` en `IssueFilter`.
- `PRB-529` propone agregar el modelo de suscriptores, pero la UI actual ya muestra la etiqueta `Subscribed`.

## Criterios de aceptación
- [ ] Mientras no exista el modelo, la UI no usa la etiqueta `Subscribed` para una consulta distinta.
- [ ] Cuando `PRB-529` esté disponible, el modo filtra por suscripción real del Actor.
- [ ] La descripción y el estado vacío explican la semántica efectiva.
- [ ] Hay regresiones para Actor asignado, creador, suscriptor y ningún resultado.

## Relación
Coordinar con `PRB-529` y `PRB-386`.
