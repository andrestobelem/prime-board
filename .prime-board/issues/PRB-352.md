# MCP: rechazar proyectos homónimos al resolver referencias

Created by admin.

## Hallazgo reproducible

`resolveProject` usa el primer proyecto cuyo nombre coincide. Con proyectos homónimos, `list_issues` y `save_issue` consultan o mutan el proyecto equivocado.

## Comportamiento esperado

Las referencias por nombre ambiguas deben fallar con `VALIDATION_FAILED`; UUID sigue siendo inequívoco.

## Criterios de aceptación

- Detectar múltiples proyectos con el mismo nombre.
- Mantener resolución por UUID.
- Agregar regresión MCP.
