# MCP: corregir importación incompatible con SDK 1.30.0

Created by admin.

## Hallazgo reproducible

La suite completa falla al cargar `apps/mcp/src/http.ts` porque importa:

`@modelcontextprotocol/sdk/server/webStandardStreamableHttp.js`

Con la dependencia instalada `@modelcontextprotocol/sdk@1.30.0`, el paquete solo publica el export `./server`; el subpath usado por la aplicación no está permitido por `package.json` aunque el archivo exista en `dist/esm/server/`.

**Evidencia:**

- `bun test --max-concurrency=5 apps/cli/test apps/server apps/web apps/mcp packages scripts/prime-board-preflight.test.ts`
- Resultado: `699 pass`, `5 skip`, `7 fail`.
- Seis fallos son pruebas de `MCP Streamable HTTP auth and protocol` y fallan con `Cannot find package '@modelcontextprotocol/sdk/server/webStandardStreamableHttp.js'`.
- `apps/mcp/test/http.test.ts` no puede iniciar el servidor HTTP por este error de importación.

## Comportamiento esperado

El transporte MCP Streamable HTTP debe cargar con la versión fijada en `apps/mcp/package.json`, o la aplicación debe usar una ruta pública soportada por esa versión. La suite focal y el hook completo deben ejecutar sin errores de resolución.

## Criterios de aceptación

- [ ] El transporte HTTP importa solo APIs públicas compatibles con la dependencia fijada, o se actualiza la dependencia con una decisión explícita.
- [ ] Las pruebas MCP de autenticación, sesión, aislamiento y tools pasan.
- [ ] `bun run typecheck` y la suite completa pasan, salvo brechas independientes documentadas.
- [ ] La solución no depende de rutas internas no exportadas del paquete.
