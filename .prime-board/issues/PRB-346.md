# Relations: emitir webhook para ambos extremos al crear relación

Created by admin.

## Hallazgo reproducible

`issueRelationCreate` registra actividad y actualiza ambos issues, pero el resolver solo emite `issue.updated` para el extremo `created.issue`. Al borrar la relación sí emite eventos para ambos extremos.

## Comportamiento esperado

Los webhooks deben tener la misma semántica en create y delete: cada issue afectado recibe su evento `issue.updated`, con la relación e inversa correspondientes.

## Criterios de aceptación

- Crear relación emite `issue.updated` para ambos issues.
- El payload usa el tipo correcto desde cada extremo.
- Agregar regresión de entrega de eventos.
