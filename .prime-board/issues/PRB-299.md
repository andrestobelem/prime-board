# MCP: gestionar webhooks con paridad respecto de GraphQL y CLI

Created by admin.

## Hallazgo reproducible

GraphQL expone `webhooks`, `webhookCreate` y `webhookDelete`, y `pb webhook list|create|delete` ya existe. Sin embargo `apps/mcp/src/server.ts` no registra ninguna herramienta para webhooks: un cliente MCP no puede listar suscripciones, crear una URL firmada ni borrar una suscripción sin GraphQL/CLI directo.

Esto contradice la paridad declarada en `docs/guia-agentes.md` y deja incompleto el flujo operativo de un agente que solo tiene MCP.

## Comportamiento esperado

MCP debe exponer las operaciones de webhook soportadas por la política de ownership actual, incluyendo eventos, validación, secret de una sola lectura, errores y borrado autorizado.

## Criterios de aceptación

- Tools para listar, crear y borrar webhooks con schemas explícitos.
- El secret solo aparece en la respuesta de creación y nunca en list/get.
- Se mantienen ownership, firma, eventos inválidos y códigos de error.
- Agregar tests de contrato MCP y actualizar la guía/matriz de capacidades.
