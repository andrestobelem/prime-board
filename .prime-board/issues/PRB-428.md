# Crear migrator PostgreSQL con lock y checksums

Created by admin.

## What to build
Implementar migraciones PostgreSQL versionadas, idempotentes y coordinadas entre instancias concurrentes.

## Acceptance criteria
- [ ] El migrator registra versión, nombre, checksum y fecha de aplicación.
- [ ] Dos arranques concurrentes no aplican dos veces el mismo cambio.
- [ ] Un checksum alterado o una migración fallida detiene el arranque de forma segura.
- [ ] Las migraciones futuras quedan separadas de los SQL específicos de SQLite.
