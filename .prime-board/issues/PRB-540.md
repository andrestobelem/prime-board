# Simplificar estados y separar handoff humano del workflow operativo

Created by admin.

## Hallazgo

El Team `PRB` tiene diez estados: `Needs Triage`, `Backlog`, `Todo`, `In Progress`, `Done`, `Canceled`, `Ready for Agent`, `Ready for Human`, `Needs Info` y `Duplicate`.

El workflow mezcla ciclo operativo, triage y handoff. `Backlog` y `Todo` no tienen una diferencia operativa clara. `Ready for Human` está documentado como implementación humana, pero se usó como si significara revisión de una entrega de un agente. `Duplicate` duplica parte de la semántica de `Canceled`.

## Resultado esperado

Definir un modelo de estados pequeño y explícito que distinga:

- triage y falta de información;
- trabajo listo para un agente;
- trabajo listo para una persona;
- trabajo en curso;
- finalización y cancelación.

## Criterios de aceptación

- Se documenta el significado y el responsable de cada estado.
- Se elimina la redundancia entre `Backlog` y `Todo`, o se documenta una diferencia verificable.
- Se separa la revisión de entregas del estado que significa implementación humana.
- Se decide si `Duplicate` debe ser un estado o una relación `duplicate-of` con `Canceled`.
- Se migran Issues existentes sin perder trazabilidad y se actualizan las skills y la documentación.
