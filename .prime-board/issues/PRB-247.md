# Rebuild parcial: saved views fuera del alcance rompen --allow-partial

Created by admin.

## Evidencia

En una ejecución real contra la DB operativa:

```bash
bun run export --out /tmp/pb-export --team PRB
PRIME_BOARD_DB=/tmp/pb-partial.db bun run rebuild --from /tmp/pb-export --allow-partial
```

El export registra `meta/export.json` con `scope: team:PRB` y contiene saved views que referencian el team histórico `AT`. El rebuild con `--allow-partial` falla dentro de la transacción con `Saved view "A View" references unknown team AT`. Sin el flag, rechaza correctamente el export parcial.

## Comportamiento esperado

Un export team-scoped aceptado explícitamente debe reconstruir el alcance seleccionado sin intentar resolver referencias de entidades fuera de ese alcance, o debe emitir un diagnóstico específico y documentado antes de iniciar la reconstrucción. No debe fallar por una saved view ajena después de aceptar `--allow-partial`.

## Criterios de aceptación

- [ ] `--allow-partial` reconstruye un export parcial válido sin referencias cruzadas ajenas, o rechaza antes de mutar con un diagnóstico accionable.
- [ ] Las saved views y sus filtros se conservan cuando pertenecen al team exportado.
- [ ] La DB no queda parcialmente modificada cuando falla la validación.
- [ ] Hay pruebas de export parcial, referencias cruzadas y round-trip.
