# La UI puede quedar cacheada vieja: servir index.html con no-cache

Created by admin.

Al servir la UI estática, el server no manda `Cache-Control`. El browser puede retener un `index.html` viejo que apunta a bundles anteriores: tras un rebuild, el usuario ve la UI desactualizada hasta un hard reload (pasó en vivo buscando el switcher, que el bundle nuevo sí tenía).

Arreglo: `Cache-Control: no-cache` para los HTML (se revalidan siempre) y `max-age` largo + `immutable` para los assets hasheados de Vite (`/assets/*`), que cambian de nombre en cada build.

*Encontrado asistiendo a un usuario que veía una UI vieja.*
