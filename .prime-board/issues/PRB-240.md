# Frontend: permitir asignar cycles y crear sub-issues

Created by admin.

## Origen

Auditoría integral PRB-228 / sub-issue PRB-233.

## Problema

La API, CLI y MCP soportan `cycleId`, pero el frontend no muestra ni edita el cycle de un issue. El frontend muestra sub-issues, pero no permite crear uno con `parentId` desde el issue padre.

## Alcance

Resolver la funcionalidad, no todavía la comparación estética/usabilidad con Linear.

## Criterios de aceptación

- [ ] El detalle de issue permite asignar/quitar cycle cuando corresponda.
- [ ] El detalle permite crear un sub-issue y lo muestra después de crearlo.
- [ ] Estados loading, error y actualización quedan cubiertos.
- [ ] La lista/board no pierde issues por el límite de 250 o documenta/implementa paginación.
