# prime-status no muestra el widget tras reload

Created by admin.

## Evidencia
La extensión actualiza `setStatus()` y `setWidget()` en `session_start`, `turn_start` y `turn_end`, pero después de instalar y ejecutar `/reload` no aparece ninguna línea.

Una reproducción aislada de la TUI muestra que un widget emitido durante `input` sí se renderiza, mientras que el widget emitido solo durante `session_start` no queda visible en el primer render.

## Comportamiento esperado
Después de `/reload` o al escribir el siguiente prompt, debe aparecer `cwd: ... | session: ...`.

## Criterios de aceptación
- Actualizar el widget también en `input`.
- Mantener `setStatus()` y compatibilidad con daemon.
- Agregar regresión.
