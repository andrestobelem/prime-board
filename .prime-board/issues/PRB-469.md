# Webhooks: emitir project.updated al archivar y restaurar proyectos

Created by admin.

## Objetivo
Emitir `project.updated` cuando `projectArchive` o `projectUnarchive` cambian el estado de un Project.

## Evidencia
La auditoría de PRB-1..349 encontró que `project-resolvers.ts` actualiza la DB y devuelve el Project, pero no llama al dispatcher de eventos. El contrato de eventos y `projectUpdate` ya declaran y emiten `project.updated`.

## Criterios de aceptación
- Archivar un Project entrega un evento `project.updated` con el cambio de `archivedAt`.
- Restaurar un Project entrega un evento equivalente con el cambio inverso.
- El evento respeta autorización, actor, Workspace y entrega webhook existentes.
- Hay regresiones GraphQL/webhook para archive y unarchive; los casos inexistentes no emiten eventos.
