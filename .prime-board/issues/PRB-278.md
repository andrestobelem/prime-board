# Auditar paridad visual y usabilidad con Linear

Created by admin.

## Objetivo

Revisar la UI de prime-board contra Linear para conservar el look & feel y los flujos de usabilidad que aportan valor, sin intentar clonar capacidades ajenas al board orientado a agentes.

## Alcance

- Comparar shell, navegación, sidebar, lista/board, detalle de issue, filtros, búsqueda, command palette, modales, responsive y accesibilidad.
- Contrastar la superficie funcional visible con la API/CLI/MCP existente.
- Separar lo que ya está bien, diferencias conocidas aceptables, faltantes imprescindibles y mejoras deseables.
- Dejar fuera documentos colaborativos, roadmaps/analytics, integraciones enterprise/sociales y otras capacidades sin valor para agentes.

## Entregables

- Informe Markdown con evidencia en el código y fuentes primarias de Linear.
- Matriz de paridad clasificada como imprescindible, deseable o fuera de alcance.
- Tickets accionables para los faltantes que decidamos conservar.

## Criterios de aceptación

- Cada diferencia tiene referencia verificable y comportamiento esperado.
- Se explicita qué no se va a copiar y por qué.
- No se implementan cambios de producto dentro de esta auditoría.
- El informe permite priorizar una siguiente tanda de trabajo sin volver a relevar todo.
