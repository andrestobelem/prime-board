# Probar prime-status con widget visible

Created by admin.

## Contexto
La extensión `prime-status` usa `ctx.ui.setStatus()`, pero la TUI Prime actual mantiene el footer integrado vacío y no muestra el estado.

## Objetivo
Agregar temporalmente un widget visible para comprobar si `ctx.ui.setWidget()` permite mostrar `cwd` y nombre de sesión en la sesión interactiva y mediante daemon.

## Criterios de aceptación
- Conserva la llamada a `ctx.ui.setStatus()`.
- Muestra la misma información mediante `ctx.ui.setWidget()`.
- Mantiene compatibilidad con daemon/RPC.
- Tests y typecheck pasan.
