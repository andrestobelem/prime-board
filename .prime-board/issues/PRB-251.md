# Frontend: detalle de issue sin acciones y navegación de contexto

Created by admin.

## Divergencia

El detalle local (`/#/issue/PRB-240`) resuelve edición, relaciones, comentarios, actividad y propiedades, pero no ofrece las affordances de navegación y acciones visibles del detalle de Linear: menú de acciones junto al identificador, favorito, enlace/copia y navegación anterior/siguiente. Las propiedades aparecen como selects planos sin la jerarquía/indicadores de propiedad de Linear.

## Evidencia

- Captura local: `/tmp/pb-issue.png` (viewport 1440×1000).
- Referencia oficial de Linear: [Parent and sub-issues](https://linear.app/docs/parent-and-sub-issues), cuya captura muestra menú de acciones, navegación del issue, propiedades con iconos y el bloque de sub-issues.

## Comportamiento esperado

El detalle debe conservar todas las capacidades actuales y sumar acciones de contexto y navegación reconocibles, con una jerarquía visual de propiedades consistente con Linear.

## Criterios de aceptación

- [ ] El encabezado ofrece acciones de issue, copiar/enlazar y navegación entre issues sin ocultar el identificador.
- [ ] Las propiedades muestran labels/indicadores consistentes y feedback claro al actualizar.
- [ ] El bloque de sub-issues conserva creación inline y ofrece acciones equivalentes de sección.
- [ ] Se mantiene accesible por teclado y responsive.
