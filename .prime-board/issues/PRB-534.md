# Inbox: mostrar estado y error recuperable en acciones de receipts

Created by admin.

## Objetivo
Hacer visibles y recuperables los fallos de Mark read y Archive en Inbox.

## Evidencia
- `apps/web/src/views/InboxView.tsx` dispara `inboxMarkRead` e `inboxArchive` sin `catch` ni estado pending por entrada.
- La paginación sí muestra error, pero las mutaciones pueden dejar el badge y la lista desincronizados.

## Criterios de aceptación
- [ ] Cada acción muestra estado pending y bloquea doble click.
- [ ] El estado local cambia solo después del éxito del servidor, o se revierte si el update es optimista.
- [ ] Un error muestra mensaje y Retry para la entrada afectada.
- [ ] El contador no leído y la lista quedan consistentes después de éxito, fallo y recarga.
- [ ] Hay regresiones con permisos insuficientes y error de red.
