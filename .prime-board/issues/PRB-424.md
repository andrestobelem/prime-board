# Mantener SQLite detrás del nuevo contrato

Created by admin.

## What to build
Conservar SQLite como backend de compatibilidad detrás del contrato async, de modo que el comportamiento actual siga funcionando durante la migración gradual.

## Acceptance criteria
- [ ] El backend SQLite implementa todas las operaciones del contrato sin exponer tipos del driver al dominio.
- [ ] La suite existente permanece verde y conserva transacciones, foreign keys y export/import.
- [ ] La selección de backend permite volver a SQLite sin revertir los módulos ya migrados.

## Blocked by
