# UI: gestión de usuarios y agentes (members)

Hoy los actores (humanos y agentes) solo se pueden crear por GraphQL/CLI/MCP (`actorCreate` + `apiKeyCreate`). Falta la administración desde la UI:

* **Sección "Members"** (en el sidebar o dentro de Settings): listado de actores con nombre, tipo (badge 🤖 para agentes), email y fecha de alta.
* **Alta de actores** desde la UI: humano o agente, con nombre y email opcional.
* **API keys por actor**: generar una key desde la UI (mostrada una única vez, con botón de copiar) y listar las existentes con `lastUsedAt`; idealmente poder **revocarlas** (requiere mutation `apiKeyDelete`, hoy inexistente — agregarla al schema).
* Reutilizar el patrón `/?key=` para generar un **link de onboarding** copiable al crear un actor con su key.

**Entregable:** flujo completo desde la UI: crear un agente → generar su key → copiar el link de onboarding → el agente opera con esa key. Verificación visual con Playwright.

Origen: feedback de Andrés al probar el MVP.
