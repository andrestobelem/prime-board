# Rebuild: issues.cycle_id no sobrevive export/import

Created by admin.

## Evidencia

`exportBoard` escribe `meta/cycles.json` y el importer los recrea, pero:

- el front-matter del Issue Markdown **no** incluye `cycle`
- el `INSERT` de issues en `rebuildFromRepo` **no** setea `cycle_id`
- el replay del log solo inserta filas en `activity`/`comments`; **no** reaplica cambios de campo al issue

Consecuencia: tras `bun run rebuild`, los ciclos existen pero ningún issue queda asignado.

El test de PRB-211 solo verifica que el ciclo reaparece en la tabla `cycles`, no la asignación issue↔ciclo.

## Esperado

Round-trip completo: issue asignado a un ciclo vuelve asignado tras rebuild.

## Criterios de aceptación

- Front-matter (o campo equivalente estable) con referencia legible al ciclo (p. ej. `team/number` o `team/name`).
- Importer restaura `issues.cycle_id`.
- Test export → rebuild afirma la asignación, no solo la existencia del ciclo.
