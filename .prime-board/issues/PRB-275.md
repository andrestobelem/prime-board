# CLI/MCP: exponer cycles, reviews, initiatives, inbox y favorites

Created by admin.

## Hallazgo reproducible

Varias capacidades públicas del schema carecen de interfaz CLI/MCP, impidiendo que un agente opere el board sin usar GraphQL directo.

## Evidencia

El schema expone queries/mutations para `cycles`, `reviews`, `initiatives`, `inbox` y `favorites` (`cycleCreate/Update/Delete/CarryOver`, `reviewCreate/Update/Delete`, `initiativeCreate/Update/Delete`, `inboxMarkRead/Archive`, `favoriteCreate/Delete/Reorder`). Sin embargo:

- `apps/cli/src/index.ts` solo registra `auth`, `issue`, `project`, `view`, `team` y `webhook`.
- `apps/mcp/src/server.ts` no registra tools para esos cinco dominios.
- La guía de agentes declara paridad total entre GraphQL, CLI y MCP, que no se cumple.

## Criterios de aceptación

- Definir una matriz de capacidades pública y decidir el soporte de cada dominio.
- Exponer las operaciones soportadas de forma equivalente en CLI y MCP, o documentar explícitamente las excepciones.
- Cubrir resolución de referencias, paginación/filtros, autorización y errores.
- Agregar tests de contrato y actualizar la guía de agentes.
