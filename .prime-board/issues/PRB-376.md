# Auditoría: paridad de Settings con Linear

Created by admin.

## Objetivo
Revisar las opciones de configuración que ofrece Linear y comparar su alcance con los Settings actuales de prime-board.

## Alcance
- Consultar fuentes primarias oficiales de Linear.
- Inventariar Workspace, Team, Member/Actor, seguridad, integraciones, preferencias y administración.
- Mapear cada categoría contra la UI y API actuales de prime-board.
- Proponer gaps priorizados, sin implementar todavía.

## Criterios de aceptación
- Informe en `docs/research/linear-settings-parity.md` con fuentes oficiales enlazadas.
- Tabla de paridad: existente, parcial, ausente o fuera de alcance.
- Backlog priorizado con criterios para decidir qué incorporar.
- Validación de que no se confunden configuraciones de Linear con capacidades que prime-board no necesita por su modelo local-first/single-tenant.
