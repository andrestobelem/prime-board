# GraphQL: teams, actores y API keys

Created by Andrés Tobelem.

Queries `teams`, `team`, `actors`, `workspace` y mutations `teamCreate`, `actorCreate` (humanos y agentes), `apiKeyCreate` (devuelve la key una sola vez). Al crear un team se siembra el workflow default (Backlog, Todo, In Progress, Done, Canceled) y `workflowStateCreate` permite personalizarlo.

**Entregable:** alta de un agente con su key vía GraphQL puro. Spec de referencia: [`docs/specs/mvp.md`](<https://github.com/andrestobelem/prime-board/blob/main/docs/specs/mvp.md>).
