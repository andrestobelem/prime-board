# Issue Markdown / CLI: creator no visible fuera del front-matter

Created by admin.

## Evidencia

En `.prime-board/issues/*.md` el campo `creator` vive solo en el YAML del front-matter (ej. `creator: admin`). El cuerpo legible (`# título` + descripción) no indica quién creó el issue.

`pb issue view <id>` tampoco muestra creator: solo identifier, estado, prioridad, título, descripción y comentarios.

## Esperado

Que la autoría sea obvia al leer el snapshot o al ver el issue por CLI, sin depender de inspeccionar el front-matter.

## Criterios de aceptación

- `pb issue view` muestra el creator (nombre del actor).
- El export Issue Markdown deja la autoría visible de forma legible (p. ej. línea bajo el título o campo claramente documentado en el contrato del snapshot), sin romper import/reconcile.
- Tests cubren el nuevo formato / salida CLI.
