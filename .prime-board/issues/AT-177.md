# Filtro de issues desbloqueados (frontier)

## Parent

AT-174 — Relaciones entre issues (blocking / blocked-by)

## What to build

`issues(filter: { unblocked: true })` devuelve los issues abiertos cuyos bloqueantes están **todos cerrados**. Es la query que `/wayfinder` necesita para trabajar el frontier sin parsear texto.

## Acceptance criteria

- [ ] Un issue sin bloqueantes cuenta como desbloqueado
- [ ] Un issue con al menos un bloqueante abierto queda fuera del resultado
- [ ] Cuando el bloqueante pasa a un estado `completed`/`canceled`, el issue entra al frontier
- [ ] El filtro se combina con los demás (team, estado, assignee)
- [ ] Tests
