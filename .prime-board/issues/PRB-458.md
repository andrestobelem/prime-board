# Release y actualización segura del runtime

Created by admin.

## What to build
Un proceso reproducible de release/update que declare plataformas y garantice backup antes de migrar una DB existente.

## Acceptance criteria
- [ ] La matriz de plataformas y el requisito de Bun o binarios standalone están fijados, sin alternativas ambiguas.
- [ ] Los artefactos reproducibles tienen versión y checksums verificables.
- [ ] Una actualización crea backup antes de aplicar migraciones.
- [ ] Una migración fallida permite restaurar la DB según una política documentada.
- [ ] El update no elimina ni sobrescribe la réplica de otro proyecto.

## Test seam
Build/release/install/update/backup/restore.
