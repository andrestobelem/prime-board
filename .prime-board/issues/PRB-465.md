# Instalación: usar workspace como nombre predeterminado

Created by admin.

## Objetivo
Cuando Prime Board inicializa una instalación nueva, el Workspace debe llamarse `workspace` por defecto.

## Criterios de aceptación
- Una base SQLite nueva crea el Workspace con nombre `workspace`.
- PostgreSQL/bootstrap usa el mismo nombre.
- El `urlKey` estable predeterminado sigue siendo `prime-board` para no cambiar rutas ni referencias.
- Export/import conserva el nombre y el `urlKey` explícitos; usa `workspace` sólo como fallback del nombre.
- Los tests existentes se actualizan sin cambiar Workspaces ya creados.
