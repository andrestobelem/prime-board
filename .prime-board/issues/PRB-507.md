# Hook: aislar los tests concurrentes del launcher

Created by admin.

## Hallazgo

El hook pre-commit ejecuta en paralelo `scripts/prime-board-project.integration.test.ts` y `scripts/prime-board-project.test.ts`. Ambos crean instancias y reservas de puertos del launcher. Con `--max-concurrency=5`, el test `project launcher lifecycle` puede quedar bloqueado 15 segundos.

## Evidencia

- El hook falló dos veces con `project launcher lifecycle` tras 15.000 ms.
- La suite equivalente con `--max-concurrency=1` pasó `449/449`.
- La suite aislada de `scripts/prime-board-project.integration.test.ts` pasó `4/4`.

## Comportamiento esperado

Los tests que comparten locks y reservas del launcher deben ejecutarse sin competir entre sí. El resto de la suite debe conservar concurrencia acotada.

## Criterios de aceptación

- [ ] El hook mantiene `--max-concurrency=5` para la suite general.
- [ ] Los tests del launcher no se ejecutan en paralelo entre sí.
- [ ] El hook completo pasa sin timeouts intermitentes.
