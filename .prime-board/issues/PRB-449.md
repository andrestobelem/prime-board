# Ensayar cutover, rollback y backups operativos

Created by admin.

## What to build
Ensayar el cambio de SQLite operativo a Repository Source + PostgreSQL projector, con downtime controlado, backups y rollback medido.

## Acceptance criteria
- [ ] Se cronometran freeze, export histórico, commit del Log, replay, validación, arranque y rollback.
- [ ] Antes del corte, SQLite queda congelado; después del corte, las mutaciones solo siguen el protocolo del Repository Source.
- [ ] El rollback vuelve a la copia SQLite congelada sin destruir el volumen PostgreSQL ni perder eventos ya publicados.
- [ ] El runbook no contiene credenciales y otra persona puede repetirlo.
- [ ] Se registra una decisión go/no-go con lag de proyección, riesgos y brechas restantes.
