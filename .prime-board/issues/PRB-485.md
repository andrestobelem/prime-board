# Clientes: aislar sesión, selección y cache del MCP

Created by admin.

## Objetivo
Dar al MCP un contexto de Workspace por sesión y limpiar sus referencias al cambiarlo.

## Criterios de aceptación
- Las tools listan y seleccionan solo Workspaces concedidos o exigen configuración explícita.
- Cada tool usa el Workspace efectivo y no puede operar B con key/contexto de A.
- Cambiar Workspace invalida IDs, favoritos, Inbox y resultados cacheados del anterior.
- Transporte HTTP y stdio conservan sus contratos de bearer y configuración.
- Tests cubren sesión, referencias homónimas, errores y perfiles legacy.

## Seam de validación
`apps/mcp`, sesión HTTP/stdio, headers, cache de tools y tests MCP.

## Dependencias
Requiere `PRB-484` y `PRB-415`.
