# Adoptar entrega a revisión y coordinación poteto-mode

Created by admin.

## Resultado
Separar una entrega de agente pendiente de revisión del trabajo que requiere implementación humana.

## Criterios de aceptación
- [ ] El Team `PRB` tiene un estado operativo `Ready for Review`.
- [ ] `Ready for Human` conserva el significado de implementación o decisión humana.
- [ ] Las skills y la documentación definen claim, entrega, revisión y cierre con la misma semántica.
- [ ] La entrega exige SHA, criterios, verificación, brechas y siguiente estado.
- [ ] Los agentes avisan a `admin` cuando terminan o quedan bloqueados.
- [ ] No se migran Issues históricas ya cerradas.

## Fuera de alcance
- Crear labels, ciclos o un sistema externo de coordinación.
- Reescribir comentarios históricos.
