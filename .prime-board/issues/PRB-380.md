# API keys: agregar scopes, límites por Team, expiración y rotación

Created by admin.

## Objetivo
Extender la administración de API keys con nombre, scopes mínimos, límites por Team, expiración/rotación opcional, última utilización y revocación segura.

## Contexto
Gap identificado en `docs/research/linear-settings-parity.md` (PRB-376), categoría P0.

## Criterios de aceptación
- Una key nunca obtiene más permisos que los declarados; scopes y Team limits se aplican en GraphQL/CLI/MCP y la UI muestra el impacto.
- La implementación debe conservar el modelo local-first, single-tenant y API-first de prime-board.
- Agregar regresiones y evidencia en este issue antes de cerrarlo.
