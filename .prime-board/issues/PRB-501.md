# Agent bootstrap: las rutas de paquetes locales fallan en worktrees

Created by admin.

## Hallazgo

Al lanzar los cuatro Agents desde worktrees aisladas, el bootstrap de Prime Agent falló al instalar `prime-question` y `prime-status` desde `.prime/agent/npm/package.json`.

La ruta versionada funciona desde el checkout principal:

```json
"prime-question": "file:../../../../prime-question/prime-question-0.1.0.tgz"
```

Desde `scratchpad/worktrees/<agent>`, esa ruta no encuentra los paquetes locales. Para continuar el experimento se reescribió de forma temporal a una ruta con más niveles:

```json
"prime-question": "file:../../../../../../../prime-question/prime-question-0.1.0.tgz"
```

El mismo cambio afecta a `prime-status`, quedó no commiteado en las cuatro worktrees y ensució sus estados Git.

## Comportamiento esperado

El bootstrap debe resolver dependencias locales sin editar archivos versionados ni dejar cambios no relacionados en una worktree de Agent.

## Criterios de aceptación

- [ ] El bootstrap funciona desde el checkout principal y desde una worktree aislada.
- [ ] Las rutas locales no dependen de una profundidad fija, o se usa una estrategia portable.
- [ ] La instalación no modifica `.prime/agent/npm/package.json` durante la ejecución.
- [ ] Cuatro worktrees concurrentes quedan limpias después de completar sus commits.
