# Clientes: agregar selector de Workspace al CLI y perfiles

Created by admin.

## Objetivo
Permitir que el CLI descubra, seleccione y use un Workspace sin mezclar perfiles ni credenciales.

## Criterios de aceptación
- `pb workspace list` muestra solo Workspaces concedidos.
- `pb workspace use` o el selector de perfil persiste `workspaceId`/`urlKey` y envía `X-Workspace-ID`.
- Perfiles legacy con un solo grant siguen funcionando sin configuración adicional.
- Resolución de Team/Issue/Project/Label rechaza referencias homónimas ambiguas con un mensaje accionable.
- JSON, códigos de salida y errores GraphQL quedan cubiertos por tests de contrato.

## Seam de validación
CLI `pb`, perfiles locales, header de Workspace, resolvers de referencias y tests JSON.

## Dependencias
Requiere el contrato GraphQL de `PRB-415`.
