# Replica: definir namespace y export por Workspace

Created by admin.

## Objetivo
Exportar cada Workspace a un namespace de Repository Replica estable y sin colisiones.

## Criterios de aceptación
- El layout usa un namespace explícito, por ejemplo `.prime-board/workspaces/<urlKey>/`, con metadata, Issues y Logs propios.
- `exportBoard`, `exportIssue` y `export` exigen selector cuando hay varios Workspaces.
- Exportar A no modifica la réplica de B ni mezcla `TEAM-123`, source-map, Activity o relaciones.
- API keys y secretos de Webhooks no aparecen en ningún archivo exportado.
- El formato incluye versión, Workspace metadata y reporte de alcance.

## Seam de validación
Exporter, `RepoSync`, `.prime-board/`, source-map, logs y fixtures con dos Workspaces.

## Dependencias
Requiere `PRB-415` y `PRB-416` completos.
