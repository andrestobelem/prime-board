# CLI pb: auth e issues

Comandos `pb auth login`, `pb issue list|view|create|update|comment` contra la API GraphQL, con config en `~/.prime-board/cli.json` (override por env), `--json` estable para agentes y exit codes 0/1/2 según la spec §7.

**Entregable:** flujo completo de un issue desde la terminal. Spec de referencia: [`docs/specs/mvp.md`](<https://github.com/andrestobelem/prime-board/blob/main/docs/specs/mvp.md>).
