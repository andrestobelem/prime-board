# Replica: separar export, rebuild y sincronización Git por Workspace

Created by admin.

## Objetivo
Coordinar export, rebuild y sincronización Git por Workspace sin perder compatibilidad con el layout histórico.

## Hitos
- `PRB-482`: namespace y export por Workspace.
- `PRB-483`: rebuild, RepoSync y merges concurrentes.

## Criterios de aceptación
- Ambos hijos están `Done` con round-trip y pruebas de fallo seguro.
- Exportar o reconstruir A deja intactos los datos de B.
- Exports legacy y scopes ambiguos tienen resultados documentados.
- No se exportan API keys ni secretos de Webhooks.

## Seam de validación
Exporter, `rebuild`, RepoSync, `.prime-board/`, source-map, Logs y fixtures multi-Workspace.

## Dependencias
Requiere `PRB-415` y `PRB-416`.
