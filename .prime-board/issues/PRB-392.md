# Audit y Export: registrar administración y exportar datos

Created by admin.

## Objetivo
Agregar audit log para autenticación, API keys, permisos, membresías, Teams y Settings; ofrecer exportación operativa cuando corresponda.

## Contexto
Gap identificado en `docs/research/linear-settings-parity.md` (PRB-376), categoría P2.

## Criterios de aceptación
- Cada mutación administrativa produce evidencia consultable con actor/fecha/objeto; exportación no pierde seguridad ni referencias.
- La implementación debe conservar el modelo local-first, single-tenant y API-first de prime-board.
- Agregar regresiones y evidencia en este issue antes de cerrarlo.

## Revalidación contra Linear actual (2026-08-22)

### Ajustes de alcance

- Linear documenta Audit Log con retención de 90 días, disponible en Enterprise y accesible solo para Workspace owners.
- El export de Workspace es CSV para Issues y Members, con permisos y alcance de equipos privados dependientes del plan/rol.
- La documentación no garantiza que cada mutación administrativa produzca una entrada individual.

### Criterios adicionales

- Sustituir “cada mutación administrativa” por un inventario explícito de eventos y cambios que prime-board decide auditar.
- Separar audit log, export CSV y export API/JSON como capacidades distintas.
- Registrar actor, timestamp, objeto, acción, scope y resultado, y definir retención y permisos de consulta.
