# Extensión lifecycle por ctx.cwd

Created by admin.

## What to build
La extensión debe resolver el Git root desde `ctx.cwd`, iniciar o reutilizar el runtime y exponer comandos finos sin shell arbitrario.

## Acceptance criteria
- [ ] `session_start` resuelve un repositorio con espacios y espera `/health`.
- [ ] Reutiliza el runtime del launcher y no duplica procesos.
- [ ] Comandos `status`, `open`, `logs` y `stop` tienen contratos y errores claros.
- [ ] `session_shutdown` no mata un proceso usado por otra sesión.
- [ ] Falta de runtime/binario produce una guía accionable y no una excepción opaca.

## Test seam
ExtensionAPI events/commands + proceso + health.
