# Auditoría: documentación, configuración y seguridad operacional

Created by admin.

## Objetivo

Detectar inconsistencias entre documentación, configuración y comportamiento real, además de riesgos operativos evidentes.

## Revisar

- `AGENTS.md`, `CONTEXT.md` y documentación de agentes
- scripts, variables de entorno y setup local
- contratos publicados y ejemplos
- secretos, credenciales y datos sensibles en snapshots o logs
- acciones destructivas, mensajes de error y permisos
- nomenclatura y convenciones del dominio

## Entrega

Para cada divergencia, citar archivo o comando, comportamiento actual y propuesta esperada. No corregir todavía.
