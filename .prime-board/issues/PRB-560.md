# Web: renderizar Markdown en iniciativas y proyectos

Created by admin.

## Objetivo
Mostrar Markdown renderizado de forma consistente en todas las superficies que aceptan contenido Markdown.

## Evidencia
La aplicación ya renderiza Markdown en descripciones de issues y documentos, pero todavía muestra texto crudo en:
- Descripción de iniciativas.
- Descripción de proyectos.
- Cuerpo de actualizaciones de proyectos.
- Riesgos de actualizaciones de proyectos.

## Criterios de aceptación
- Las superficies anteriores renderizan headings, párrafos, listas, enlaces, código y saltos de línea con el renderer seguro existente.
- El contenido conserva una jerarquía visual consistente con issues y documents.
- El renderer mantiene la sanitización actual.
- Los textos vacíos conservan su estado actual.
- Hay regresiones reproducibles para las superficies corregidas.
