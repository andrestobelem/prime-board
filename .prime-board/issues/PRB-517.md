# Hacer obligatorio WorkspaceContext en los dominios multi-Workspace

Created by admin.

## Hallazgo
Varias APIs de dominio conservan `workspaceId?: string` y ramas sin filtro: `favorites.ts:40-70`, `initiatives.ts:55-110`, `saved-views.ts:67-101` y `webhooks.ts:32-52`. El contrato de `CONTEXT.md:11-13` exige que cada operación lleve contexto; una interfaz opcional permite reintroducir lecturas o escrituras sin límite de Workspace.

## Criterios de aceptación
- Las operaciones multi-Workspace reciben un `WorkspaceContext` obligatorio, o una capa única encapsula la compatibilidad legacy.
- No quedan ramas de dominio que acepten referencias desnudas en rutas operativas.
- Los resolvers y tests usan el mismo tipo de contexto.
- TypeScript y tests cubren el rechazo de contexto ausente.
