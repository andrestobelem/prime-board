# GraphQL: definir listado, selección y lifecycle de Workspace

Created by admin.

## Objetivo
Exponer el contrato GraphQL para descubrir, crear y seleccionar Workspaces de forma segura.

## Criterios de aceptación
- `workspaces` y `viewer.workspaces` listan solo Memberships accesibles con rol, estado, default y `urlKey`.
- `workspaceCreate` crea Workspace, Membership admin, Team y Workflow default en una transacción.
- `workspace` y `workspaceUpdate` operan sobre el contexto efectivo y no autorizan por `workspaceId` de input.
- Introspection, inputs, payloads y errores (`WORKSPACE_REQUIRED`, `UNAUTHORIZED`, `NOT_FOUND`) quedan documentados y cubiertos.
- Crear el segundo Workspace no copia recursos del primero fuera del bootstrap definido.

## Seam de validación
SDL, resolvers GraphQL, introspection y tests de lifecycle con dos Workspaces.

## Dependencias
Requiere `PRB-413` y `PRB-414` completos.
