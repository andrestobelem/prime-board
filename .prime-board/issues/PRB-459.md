# Package Prime Agent mínimo: manifest, instalación y skills

Created by admin.

## What to build
Un Prime Agent package localizable por npm/Git que instale el manifest `pi`, una extensión mínima y `prime-board-workflow` como skill.

## Acceptance criteria
- [ ] `prime-agent package install ... --local` descubre la extensión y la skill en una instalación limpia.
- [ ] `/reload` vuelve a cargar los recursos sin duplicarlos.
- [ ] El package declara dependencias runtime/peer correctas y no incluye secretos.
- [ ] Settings de proyecto contienen solo referencia al package y configuración no sensible.

## Test seam
Package installer + discovery + `/reload`.

## Blocked by
None — can start immediately.
