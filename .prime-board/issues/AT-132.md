# Servidor GraphQL base con auth por API key

Montar GraphQL Yoga sobre Bun en `/graphql` con schema SDL-first, contexto con `viewer` resuelto por `Authorization: Bearer pb_...` (keys hasheadas SHA-256), errores con `extensions.code` (`NOT_FOUND`, `UNAUTHORIZED`, `VALIDATION_FAILED`) y GraphiQL en dev.
