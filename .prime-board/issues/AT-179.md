## What to build

Las relaciones se pueden crear, listar y borrar desde `pb` y desde el MCP, cerrando la paridad de superficies con la API y la UI.

- [ ] `pb issue link <ID> --blocked-by <ID>` y `pb issue unlink`, con `--json` y los exit codes de siempre

- [ ] Tool equivalente en el MCP server
