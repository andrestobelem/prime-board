# Implementar el importador de entidades e issues de Linear

Created by Andrés Tobelem.

## Objetivo

Crear una importación reproducible de los datos estructurales y del estado actual de Linear a prime-board.

## Debe cubrir

Teams, actores, workflow states, labels, proyectos, milestones, prioridades, asignación, descripción, fechas, archivado, numeración, padres y referencias a proyecto/milestone.

Debe conservar los identificadores acordados en el contrato de migración y funcionar sobre una base nueva y sobre una base ya poblada.

## Aceptación

* Importación idempotente.
* No modifica datos fuera del alcance declarado.
* Rechaza entradas ambiguas o inválidas antes de escribir.
* Tiene tests de round-trip y de reejecución.
