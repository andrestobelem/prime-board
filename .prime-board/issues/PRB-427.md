# Crear baseline PostgreSQL

Created by admin.

## What to build
Crear el esquema PostgreSQL inicial equivalente al modelo actual, incluyendo constraints, índices y la estrategia de búsqueda que reemplaza FTS5.

## Acceptance criteria
- [ ] Todas las entidades de negocio y relaciones actuales existen con foreign keys, checks e índices equivalentes.
- [ ] El baseline conserva IDs y referencias necesarias para la réplica del board.
- [ ] La búsqueda full-text usa estructuras PostgreSQL derivadas y no depende de `rowid` o FTS5.
- [ ] Un PostgreSQL vacío puede inicializarse desde cero con este baseline.

## Blocked by
- Validar Bun.SQL para PostgreSQL.
- Levantar PostgreSQL reproducible con Podman.
