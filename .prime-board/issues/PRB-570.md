# Retirar la funcionalidad de Documents

Created by admin.

## Objetivo

Retirar `Documents` como funcionalidad del producto y del contrato público. Mantener sin cambios las descripciones Markdown de las Issues y las demás entidades soportadas.

## Contexto

`PRB-541` incorporó el modelo y las superficies agent-first de Documents. `PRB-545` completó su soporte en PostgreSQL. Este ticket revierte esa capacidad de forma completa y coherente.

## Alcance

- Retirar la navegación, rutas, vistas, búsquedas, formularios y acciones de Documents en la UI.
- Retirar los tipos y operaciones de Documents del SDL GraphQL y de sus resolvers.
- Retirar los comandos `pb document` y las herramientas MCP de Documents.
- Retirar el dominio, repositorios, migraciones, tablas, índices, seeds, fixtures y pruebas específicas de Documents en SQLite y PostgreSQL.
- Retirar Documents de la Repository Replica, del export/import y de los procesos de rebuild.
- Actualizar `CONTEXT.md`, ADRs, documentación, ejemplos y referencias para no presentar Documents como una capacidad vigente.
- Definir y ejecutar una política explícita para los Documents existentes. No se deben borrar datos sin una migración o exportación verificable.

## Criterios de aceptación

- [ ] La UI no ofrece entradas ni rutas operativas para Documents; una URL antigua termina en una respuesta o navegación definida y no rompe la aplicación.
- [ ] El esquema GraphQL, el CLI y MCP ya no publican operaciones de Documents.
- [ ] Una instalación nueva y una actualización existente no crean ni requieren tablas de Documents.
- [ ] La réplica funciona sin `documents.json` ni eventos de Documents.
- [ ] La política para datos existentes está implementada, documentada y verificada; no hay pérdida silenciosa.
- [ ] Las descripciones Markdown de Issues y el renderer compartido que aún se usa permanecen operativos.
- [ ] Se eliminan o actualizan las pruebas, fixtures y documentos afectados sin dejar referencias falsas a Documents.
- [ ] Pasan las suites focales, typecheck, build, Prettier y `git diff --check`.

## Fuera de alcance

- Cambiar el contenido o el renderer de las descripciones de Issues.
- Retirar Projects, Teams, Initiatives, Cycles, adjuntos o enlaces que no dependan de Documents.
- Implementar un reemplazo para Documents.
