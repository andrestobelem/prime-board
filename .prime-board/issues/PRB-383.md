# Workflow: completar descripción, estados reservados y automatizaciones

Created by admin.

## Objetivo
Completar Settings de Workflow con descripción, invariantes, estado Duplicate y automatizaciones de auto-close/auto-archive, sin romper la semántica actual.

## Contexto
Gap identificado en `docs/research/linear-settings-parity.md` (PRB-376), categoría P1.

## Criterios de aceptación
- La API y UI validan estados reservados y transiciones; export/rebuild conserva la configuración; hay regresiones.
- La implementación debe conservar el modelo local-first, single-tenant y API-first de prime-board.
- Agregar regresiones y evidencia en este issue antes de cerrarlo.

## Revalidación contra Linear actual (2026-08-22)

### Ajustes de alcance

- `Duplicate` es un estado reservado y gestionado por el sistema. Se aplica al marcar una issue como duplicada y no se puede renombrar ni personalizar.
- Auto-close y auto-archive son automatizaciones de Team. No tratarlas como transiciones libres ni como un archive manual equivalente.

### Criterios adicionales

- La API y la UI rechazan renombrar o eliminar el estado reservado `Duplicate`.
- Auto-close respeta las condiciones de elegibilidad de Linear, incluidos ciclo activo, proyecto no finalizado y sub-issues pendientes cuando correspondan.
- La documentación indica si prime-board ofrece archive manual como divergencia intencional.
