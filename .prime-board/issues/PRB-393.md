# Account: completar perfil y preferencias personales

Created by admin.

## Objetivo
Agregar perfil, nombre/email/avatar, home view, display names, editor, formato, code/review preferences y salida del Workspace, sin confundir Account con Workspace.

## Contexto
Gap identificado en `docs/research/linear-settings-parity.md` (PRB-376), categoría P2.

## Criterios de aceptación
- Cada Actor puede administrar solo sus preferencias salvo controles explícitos de admin; los datos son persistentes y exportables.
- La implementación debe conservar el modelo local-first, single-tenant y API-first de prime-board.
- Agregar regresiones y evidencia en este issue antes de cerrarlo.

## Revalidación contra Linear actual (2026-08-22)

### Ajustes de alcance

- Linear separa Profile de Preferences.
- Profile cubre avatar, name/username, email, connected accounts y leave workspace.
- Preferences cubre default home view, nombres, formato, tema, editor, desktop y auto-assign. Code & Reviews es una superficie adicional.
- En prime-board, Actor humano/agente sigue siendo una entidad de dominio distinta de un User de Linear.

### Criterios adicionales

- La autorización de cada campo de perfil y preferencia es personal, salvo controles explícitos de admin.
- Los datos son persistentes y exportables sin mezclar identidad global, Workspace Membership y Team Membership.
- Code & Reviews se implementa solo si existe una integración de código que lo justifique.
