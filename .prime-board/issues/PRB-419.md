# Web: implementar switcher, rutas y cache aislados por Workspace

Created by admin.

## Objetivo
Coordinar switcher, rutas, cache y permisos Web por Workspace.

## Hitos
- `PRB-486`: switcher, rutas y deep-links.
- `PRB-487`: cache, estado personal, permisos y accesibilidad.

## Criterios de aceptación
- Ambos hijos están `Done` con pruebas UI/e2e y accesibilidad.
- Cambio A↔B no muestra datos, Favorites, Inbox, Views ni permisos del Workspace anterior.
- Actor con una Membership, dos Memberships o estado suspendido recibe la UI correcta.
- La UI no ofrece switcher antes del contrato backend.

## Seam de validación
React shell, navegación, rutas, localStorage, cache GraphQL, Settings y e2e.

## Dependencias
Requiere `PRB-415`, `PRB-416` y `PRB-418`.
