# Launcher: la prueba de ciclo deja un proceso colgado al repetir PRB-470

Created by admin.

## Hallazgo

La validación independiente de `carorila/prb-470` (`89dcfeb`) repitió el comando específico de la Issue y encontró un fallo.

## Reproducción

```bash
cd scratchpad/worktrees/carorila
bun test scripts/prime-board-project.test.ts scripts/prime-board-project.integration.test.ts
```

Resultado observado:

- `10 pass`.
- `1 fail`: `project launcher lifecycle > reuses one process and releases its lock on termination`.
- Timeout después de `15000ms`.
- Bun informó `killed 1 dangling process`.
- Las pruebas de reserva concurrente, fallo de arranque, aislamiento y locks pasan.

La sesión de Carorila había informado verde en una ejecución anterior, por lo que el problema puede depender de repetición, limpieza o carrera.

## Comportamiento esperado

La prueba debe ser repetible y el launcher debe terminar sus procesos hijos en todos los caminos. Una ejecución no debe dejar procesos colgados ni requerir limpieza externa.

## Criterios de aceptación

- [ ] La prueba falla de forma diagnóstica o pasa de forma estable en ejecuciones repetidas.
- [ ] El launcher libera proceso, lock y recursos cuando termina el ciclo.
- [ ] La prueba no depende de un proceso residual ni de un puerto ocupado de otra ejecución.
- [ ] La suite específica pasa sin procesos dangling.
