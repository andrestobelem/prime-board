# UI: completar filtros y búsqueda en Board y Project

Created by admin.

## Objetivo
Ofrecer en Board y Project la misma búsqueda y los mismos filtros operativos que ya existen en la vista de Team.

## Evidencia
- `apps/web/src/views/TeamView.tsx` monta `IssueFilterToolbar`.
- `apps/web/src/views/BoardView.tsx` consulta `filter`, pero no monta el toolbar.
- `apps/web/src/views/ProjectView.tsx` consulta los Issues del Project, pero no ofrece búsqueda ni filtros.
- `PRB-280` y `PRB-286` cerraron el trabajo anterior, pero la diferencia sigue presente en el código actual.

## Comportamiento esperado
Una persona o un agente puede acotar la misma colección desde la vista de lista, Board y Project sin perder el contexto.

## Criterios de aceptación
- [ ] Team Board ofrece búsqueda, filtros soportados y limpieza de filtros.
- [ ] Project list y Project Board ofrecen búsqueda y filtros válidos para el alcance del Project.
- [ ] Los filtros se conservan al cargar más resultados y al cambiar entre list y Board.
- [ ] La selección y las acciones bulk respetan el conjunto filtrado.
- [ ] Hay regresiones para búsqueda, filtros, paginación y cambio de layout.

## Fuera de alcance
La composición OR avanzada queda para un ticket separado si se decide incorporarla a la UI.
