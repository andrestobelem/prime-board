# Project Board: anunciar estados incompatibles y ofrecer Move to

Created by admin.

## Objetivo
Evitar drops que aparentan éxito pero no cambian una Issue en un Project multi-Team.

## Evidencia
- `apps/web/src/views/BoardView.tsx` fusiona columnas por estado y retorna sin mensaje si el Team de la Issue no tiene un state equivalente.
- El usuario ve el drag, pero la Issue permanece sin cambios.

## Criterios de aceptación
- [ ] El Board identifica columnas sin estado equivalente para el Team de la Issue.
- [ ] Un drop incompatible no inicia una mutación silenciosa.
- [ ] La UI explica la incompatibilidad con un mensaje accesible.
- [ ] Existe una acción `Move to…` o selector equivalente cuando el cambio es válido.
- [ ] Hay regresiones con un Project de dos Teams con workflows distintos.
