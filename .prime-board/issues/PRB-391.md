# Projects e Initiatives: completar Settings de planificación

Created by admin.

## Objetivo
Agregar configuración de lead, miembros/Teams, status, fechas, milestones, dependencias, templates, notificaciones y propiedades de Initiatives.

## Contexto
Gap identificado en `docs/research/linear-settings-parity.md` (PRB-376), categoría P2.

## Criterios de aceptación
- La configuración respeta ACL, se muestra en UI/CLI/MCP y export/rebuild conserva relaciones.
- La implementación debe conservar el modelo local-first, single-tenant y API-first de prime-board.
- Agregar regresiones y evidencia en este issue antes de cerrarlo.

## Revalidación contra Linear actual (2026-08-22)

### Ajustes de alcance

- Separar Project Settings de Initiative Settings.
- Projects cubre lead, members, Teams, status, fechas, milestones, dependencias, templates y notificaciones.
- Initiatives cubre status, priority, labels, owner, lead team, target date, resources, updates y proyectos asociados.
- Templates pertenecen a PRB-385. Canales y categorías de notificación pertenecen a PRB-386. Views pertenecen a PRB-390.
- Team initiatives son Business/Enterprise. Initiative Views son Enterprise.

### Criterios adicionales

- La API y la UI aplican ACL separadas para Project e Initiative.
- Export/rebuild conserva las relaciones Project–Team, Project–Milestone, Project–Initiative y sus dependencias.
- La documentación distingue propiedades soportadas de cada recurso y plan gates.
