# UI: completar acciones de issues en lista, board y command menu

Created by admin.

## Contexto
La auditoría PRB-278 confirma que la UI ya permite seleccionar issues y cambiar estados, pero Linear mantiene una superficie de acciones consistente entre lista, board, teclado, command menu y menú contextual.

## Evidencia
- `apps/web/src/components/IssueFilterToolbar.tsx` solo expone bulk state.
- `apps/web/src/components/Palette.tsx` navega/crea/cambia tema, pero no ejecuta acciones contextuales sobre una issue.
- `apps/web/src/components/IssueList.tsx` y `BoardView.tsx` no ofrecen el conjunto de atajos/menú contextual de selección.

## Comportamiento esperado
Una issue resaltada o seleccionada debe poder operar las acciones soportadas desde lista y board sin depender de abrir el detalle.

## Criterios de aceptación
- [ ] Implementar `X`, `Shift+X` y `Cmd/Ctrl+A` con foco visible y limpieza por `Esc`.
- [ ] Agregar acciones bulk para estado, assignee, priority, labels, project, cycle y archive cuando la API las soporte.
- [ ] Agregar menú contextual/overflow consistente para fila y card.
- [ ] Hacer contextual `Cmd/Ctrl+K` y agregar ayuda `?` para los atajos soportados.
- [ ] Mantener paridad de acciones y estados de error entre lista y board.
