# Web: implementar switcher, rutas y deep-links de Workspace

Created by admin.

## Objetivo
Permitir el cambio explícito de Workspace en el shell web solo cuando el backend lo soporte.

## Criterios de aceptación
- Sidebar y switcher listan únicamente Workspaces accesibles y muestran el activo.
- Rutas y deep-links validan el contexto antes de abrir Team/Issue/Project.
- El cambio A↔B es atómico, recarga shell/datos y no muestra contenido previo.
- Refresh restaura un Workspace permitido; uno no permitido muestra error sin datos.
- La UI no ofrece el switcher antes de que el servidor exponga el contrato.

## Seam de validación
React shell, navegación, rutas, GraphQL client y tests UI/e2e.

## Dependencias
Requiere `PRB-478` y `PRB-484`.
