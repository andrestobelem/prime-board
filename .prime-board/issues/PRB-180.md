# El estado default de un team es implícito (posición más baja)

`createIssue` usa **el estado de menor posición** como default cuando no se especifica uno. Al agregar `Needs Triage` en la posición -1 durante el setup de las skills (PRB-173), el default del team AT cambió **en silencio**: PRB-174 se creó ahí sin que nadie lo pidiera.

En este caso el resultado fue afortunado (un issue sin triar debería empezar en *Needs Triage*), pero la regla es un footgun: reordenar estados cambia dónde caen todos los issues futuros, sin aviso.

Propuesta: estado default **explícito** por team (`teams.default_state_id`, editable desde team settings), con la posición más baja solo como fallback inicial. Mostrarlo en la UI de estados para que se vea cuál es.

*Encontrado ejecutando `/to-tickets` sobre PRB-174.*
