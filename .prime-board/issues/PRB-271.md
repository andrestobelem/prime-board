# Frontend: agregar menú de cuenta y Workspace sin affordances falsas

Created by admin.

## Hallazgo reproducible

La referencia abre desde el nombre/avatar del workspace un menú con `Settings`, `Invite and manage members`, `Switch workspace` y `Log out`. En prime-board el nombre del workspace es un bloque estático y esas acciones aparecen dispersas o no existen.

## Comportamiento esperado

El shell debe ofrecer un menú coherente para las acciones que prime-board soporte. No debe mostrar `Switch workspace` mientras el producto siga siendo single-workspace; esa decisión queda registrada en PRB-267.

## Criterios de aceptación

- [ ] El nombre/avatar del workspace abre un menú accesible por teclado y mouse.
- [ ] `Settings` y gestión de miembros navegan a las rutas existentes sin duplicar pantallas.
- [ ] Logout elimina la key de sesión local y deja la UI en el estado de conexión.
- [ ] `Switch workspace` solo aparece si PRB-267 decide soportar multi-workspace y existe una ruta funcional.
- [ ] El menú tiene foco, cierre con Escape y comportamiento responsive.
