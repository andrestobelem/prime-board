# Completar el set de íconos vendorizados (23 de 34)

AT-172 vendorizó solo los 23 íconos que la UI usa hoy en apps/web/src/components/icons.tsx. El relevamiento de scratchpad/icons (icon-scout) cubría 34 conceptos: faltan entre otros filtro, orden, más (…), comentario, link, archivar, target date/calendario, label/tag, assignee y tema claro/oscuro.

Agregar uno es copiar el path desde el SVG de Lucide al módulo (grid 24x24, stroke 2) y sumarlo al tipo IconName. Conviene hacerlo a demanda cuando una vista los necesite, o de una si aparece la UI de filtros/orden.

Ver ADR-0005: no instalar lucide-react para esto.
