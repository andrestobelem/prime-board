# MCP: exponer duplicación de Saved Views

Created by admin.

## Hallazgo reproducible

`SavedViewDuplicate` existe en GraphQL y `pb view duplicate <ID>` funciona, pero `apps/mcp/src/server.ts` no registra `duplicate_saved_view`. Un agente MCP puede listar/crear/editar/borrar vistas, pero no reutilizar una vista existente conservando su filtro, orden, agrupación y columnas.

Evidencia: `packages/schema/src/sdl.ts` expone `savedViewDuplicate`; `apps/cli/src/commands/view.ts` implementa `duplicate`; la lista de tools MCP solo contiene operaciones list/save/delete para saved views. PRB-208/209 cubren lifecycle y superficies base, no esta operación MCP.

## Comportamiento esperado

MCP debe ofrecer duplicación con la misma resolución de referencia, visibilidad, autorización y payload que GraphQL/CLI.

## Criterios de aceptación

- Registrar `duplicate_saved_view` con id/ref y respuesta de la nueva vista.
- Preservar filtro, orden, grouping, columnas y scope permitido.
- Rechazar vistas no visibles con error estable.
- Agregar test de contrato y documentar la tool.
