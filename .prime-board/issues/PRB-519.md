# Agregar temas Catppuccin a la UI web

Created by admin.

## Objetivo
Agregar soporte de temas Catppuccin en la UI web de prime-board.

## Alcance
- Agregar los cuatro flavors oficiales: Latte, Frappé, Macchiato y Mocha.
- Mantener `system` como preferencia y resolverlo a Latte o Mocha según el sistema operativo.
- Usar tokens semánticos para fondos, superficies, bordes, texto, acento y estados.
- Mantener la preferencia aislada por Workspace y Actor.
- Exponer los temas en Settings y en la command palette.
- Evitar FOUC en la carga inicial.
- Conservar compatibilidad con las preferencias `dark`, `light` y `system` existentes.
- Documentar la atribución y licencia MIT de Catppuccin.

## Criterios de aceptación
- [ ] Settings permite elegir System, Catppuccin Latte, Catppuccin Frappé, Catppuccin Macchiato y Catppuccin Mocha.
- [ ] La command palette ofrece las mismas opciones.
- [ ] La selección se conserva al recargar y queda aislada por Workspace y Actor.
- [ ] `system` usa Latte con preferencia clara y Mocha con preferencia oscura.
- [ ] La carga inicial no muestra un tema incorrecto antes de React.
- [ ] La UI usa los tokens Catppuccin en controles, superficies, texto, errores, estados y foco.
- [ ] Se conservan y validan las preferencias legacy `dark`, `light` y `system`.
- [ ] Hay tests focalizados y pasan typecheck, tests y build web.
- [ ] La licencia MIT y la fuente oficial quedan documentadas.
