# IssueView: liberar navegación al cambiar de issue durante paginación

Created by admin.

## Hallazgo reproducible

`IssueView.loadNavigationPage` no libera `navigationLoading` si cambia el issue/team mientras la request anterior está pendiente: la generación invalida el `finally`, el nuevo efecto no resetea el flag y los botones quedan deshabilitados.

## Criterios de aceptación

- Cambiar de issue durante Load more deja navegación disponible.
- La request obsoleta no modifica resultados del issue nuevo.
- Agregar regresión.
