# MCP: añadir tools para Webhooks y duplicación de Saved Views

Created by admin.

## Hallazgo reproducible

`apps/cli/src/commands/webhook.ts` implementa list/create/delete y `view.ts` implementa `savedViewDuplicate`, pero `apps/mcp/src/server.ts` no registra `webhookCreate/Delete` ni `savedViewDuplicate`; el inventario e2e de `apps/mcp/test/mcp.test.ts` tampoco los contiene. El SDL sí expone `webhooks`, `webhookCreate/Delete` y `savedViewDuplicate`.

La matriz (`docs/alcance-mvp.md:35`) declara Webhooks GraphQL/CLI/MCP = Sí y `docs/guia-agentes.md:45` afirma paridad total.

## Comportamiento esperado

MCP debe ofrecer las mismas capacidades operativas que CLI/API para administrar webhooks y duplicar una Saved View, incluyendo ownership, secret one-shot, errores y autorización.

## Criterios de aceptación

- `list_tools` incluye tools MCP para listar/crear/borrar webhooks y duplicar Saved Views.
- Los schemas de input/output documentan el secret one-shot y las reglas de ownership/error.
- Tests e2e cubren éxito, permisos, recurso inexistente y la respuesta de duplicación.
- La matriz se corrige si alguna operación se decide explícitamente fuera de MCP.

## Duplicados/relación

PRB-260/275 son auditorías generales; PRB-209 trata export/import y clientes de Saved Views; PRB-234 trata documentación. Son contexto relacionado, no cubren estas tools ausentes.
