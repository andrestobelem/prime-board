# Web: mantener el popup de Workspace dentro del viewport

Created by Builder.

## Hallazgo de revisión de PRB-588

El popup del selector de Workspace queda fuera del viewport cuando contiene muchos elementos. `workspace-menu-popup` inicia debajo del trigger, pero `max-height: calc(100vh - 24px)` no descuenta ese desplazamiento. En desktop el final puede quedar aproximadamente 24px fuera; en el drawer mobile el desplazamiento incluye el botón de cierre y puede dejar aproximadamente 66px fuera.

El popup tiene `overflow-y: auto`, pero parte de su scrollport queda fuera del viewport fijo y la lista puede no ser completamente visible o usable.

## Comportamiento esperado

El popup debe mantenerse dentro del viewport en desktop y mobile. Una lista larga debe poder desplazarse dentro del popup sin que su scrollport quede recortado por el viewport.

## Criterios de aceptación

- [ ] La altura máxima descuenta la posición real del popup en desktop.
- [ ] La altura máxima descuenta el botón de cierre y el trigger en mobile.
- [ ] Una lista larga conserva un scrollport completamente visible.
- [ ] Existe regresión automatizada para las reglas de geometría desktop y mobile.
- [ ] La corrección mantiene el popup fuera del contenedor scrollable del Sidebar de PRB-588.

## Relación

Follow-up de PRB-588: evita el clipping vertical del mismo popup después de separar el scroll horizontal del Sidebar.
