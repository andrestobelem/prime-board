# Inbox: liberar Load more tras refetch concurrente

Created by admin.

## Hallazgo reproducible

Si Mark read/Archive dispara un refetch mientras Inbox carga otra página, el efecto incrementa la generación y el `finally` de la request obsoleta no limpia `loadingMore`. El botón queda en Loading permanentemente.

## Criterios de aceptación

- Resetear loading al invalidar una página.
- La request obsoleta no mezcla entradas.
- Agregar regresión.
