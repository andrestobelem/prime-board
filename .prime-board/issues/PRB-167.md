# Convención: skills del repo en .agents con el Skills CLI

Created by claude.

AGENTS.md menciona el Skills CLI pero no dónde aterrizan las skills ni con qué flags. Definir y documentar la convención:

- Destino: **`.agents/skills/`** (convención genérica, no atada a un agente).
- **Copias, no symlinks**, para que las skills viajen en el repo.
- Dejar el comando exacto en AGENTS.md y `skills-lock.json` versionado.
