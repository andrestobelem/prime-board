# Web: unificar confirmación o undo para acciones de archive

Created by admin.

## Objetivo
Evitar archivados accidentales y ofrecer recuperación clara desde todos los puntos de entrada.

## Evidencia
- El detalle confirma el archive, pero filas, cards, bulk, shortcut, Palette, Project y Saved View tienen caminos directos.
- `IssueActions.tsx` ejecuta archive individual y bulk sin confirmación uniforme.
- No hay undo visible para una acción exitosa.

## Criterios de aceptación
- [ ] Cada punto de entrada aplica confirmación o una acción undo documentada.
- [ ] La confirmación bulk indica la cantidad y conserva la selección al cancelar.
- [ ] Un error no cierra el menú ni pierde el contexto.
- [ ] La UI no ofrece una acción irreversible sin feedback.
- [ ] Hay regresiones de cancel, error y éxito para Issue, Project y Saved View.
