# Webhooks: emitir issue.updated al borrar recursos con issues afectadas

Created by admin.

## Hallazgo reproducible

Borrar cycles, milestones, workflow states o labels actualiza issues, updated_at y actividad, pero los resolvers no emiten `issue.updated` por los issues afectados. Webhook consumers pierden cambios observables y cursores incrementales.

## Comportamiento esperado

Toda mutación que cambie metadata observable de issues debe emitir eventos issue.updated para cada issue afectado, con changes coherentes.

## Criterios de aceptación

- Resource deletes emiten eventos para issues afectados.
- No emitir eventos para issues no afectados.
- Regresiones de webhook.
