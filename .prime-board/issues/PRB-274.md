# CLI/MCP: completar paridad con las operaciones de proyectos y planificación

Created by admin.

## Hallazgo reproducible

El schema GraphQL expone operaciones que los clientes para agentes no ofrecen. El CLI `pb project` solo tiene `list|view|create` y el MCP solo `list_projects|get_project|save_project`; no existe una operación cliente para archivar/desarchivar proyectos ni para crear/editar/borrar milestones o project updates.

## Evidencia

- `packages/schema/src/sdl.ts` expone `projectArchive`, `projectUnarchive`, `milestoneCreate`, `milestoneUpdate`, `milestoneDelete`, `projectUpdateCreate` y `projectUpdateDelete`.
- `apps/cli/src/commands/project.ts` no registra esas acciones.
- `apps/mcp/src/server.ts` no registra tools para esas mutaciones.
- La guía afirma «Paridad total: GraphQL, CLI y MCP pueden hacer exactamente lo mismo», pero la matriz actual no cumple ese contrato.

## Criterios de aceptación

- Exponer operaciones equivalentes en CLI y MCP con referencias y errores consistentes.
- Cubrir archive/unarchive y el ciclo de vida de milestones/project updates.
- Mantener códigos de salida CLI y errores MCP con códigos GraphQL.
- Agregar tests de contrato para cada operación y actualizar la ayuda/documentación.
