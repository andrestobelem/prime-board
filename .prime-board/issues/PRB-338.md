# MCP: permitir filtrar labels por ID sin team

Created by admin.

## Hallazgo reproducible

Durante la revisión del diff de PRB-326, la tool MCP `list_issues` documenta que acepta IDs de labels sin `team`, pero `apps/mcp/src/server.ts` rechaza siempre cualquier `labels` sin `team` antes de llamar a `resolveLabelIds`. Por eso un agente no puede filtrar por un label conocido por ID si no conoce también el team.

## Comportamiento esperado

`list_issues` debe aceptar IDs de labels sin `team`; solo la resolución de nombres debe requerir team. La documentación del schema de la tool y el comportamiento deben coincidir.

## Criterios de aceptación

- Filtrar por uno o más label IDs sin pasar `team`.
- Mantener el requisito de `team` para resolver nombres de labels.
- Agregar una regresión MCP que cubra el caso por ID.
