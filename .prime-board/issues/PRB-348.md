# Auth: permitir que workspace admin gestione memberships sin pertenecer al team

Created by admin.

## Hallazgo reproducible

`TeamSettingsView` considera que un workspace admin puede gestionar memberships aunque no pertenezca al team. Sin embargo, `teamMembershipCreate/Delete` delega a `assertTeamOwner`, que exige membership OWNER y rechaza al admin sin membership.

## Comportamiento esperado

El workspace admin debe poder administrar memberships de cualquier team, incluso si fue removido del roster. La UI y la API deben compartir el bypass administrativo.

## Criterios de aceptación

- Admin sin membership puede crear y borrar memberships.
- Owner de team mantiene la capacidad.
- Member/outsider no puede mutar memberships.
- Agregar regresiones GraphQL.
