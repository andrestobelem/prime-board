# UI: liberar estados de paginación al invalidar requests obsoletas

Created by admin.

## Hallazgo reproducible

Si cambia la ruta/filtro mientras una request de Load more está pendiente, la generación invalida el `finally` y varios views quedan con `loadingMore`/`navigationLoading` en `true`. Afecta Issue, Inbox, Team, My Issues, Cycle y Saved View.

## Comportamiento esperado

Invalidar una generación debe limpiar el estado de carga del contexto actual y mantener los controles utilizables.

## Criterios de aceptación

- Resetear flags al cambiar key o datos base.
- No mezclar respuestas obsoletas.
- Regresión de request generation/paginación.
