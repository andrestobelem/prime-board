# Definir contrato del event log y projector PostgreSQL

Created by admin.

## What to build
Cerrar el contrato del event log canónico y del projector para la topología PostgreSQL en la que el Repository Source es la autoridad del estado compartido.

## Acceptance criteria
- [ ] Se define el envelope de eventos: schemaVersion, eventId, agregado/clave estable, tipo, actor, occurredAt, causalidad y payload autosuficiente.
- [ ] Se define el protocolo append → commit Git → project PostgreSQL, con idempotencia, checkpoints, replay y estados de lag/falla.
- [ ] Se define el alcance: estado compartido en el Log; secrets y proyecciones personales fuera del repo.
- [ ] El importador Markdown solo puede emitir eventos explícitos; nunca escribe directamente en PostgreSQL.
- [ ] Se documenta el conflicto de numeración de Issues entre branches y la regla de resolución.
- [ ] ADR-0017, CONTEXT.md y los tickets de export/import/data pump quedan alineados.
