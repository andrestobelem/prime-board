# Relaciones entre issues (blocking / blocked-by)

Created by claude.

La skill `/to-tickets` de Pocock distingue dos mundos: *"edges as text in one file per ticket locally, **or native blocking links on a real tracker**"*. prime-board está configurado como *real tracker* pero solo soporta el fallback de texto: las dependencias se escriben en el cuerpo.

**No es un bloqueo** — `/to-tickets` funciona igual. Lo que se pierde es que las aristas sean **consultables**: el *frontier* de `/wayfinder` ("tickets cuyos bloqueantes están todos hechos") es una query con relaciones nativas, y un parseo de texto sin ellas.

Alcance propuesto: tabla `issue_relations` (issue_id, related_id, type) con `blocks`/`blocked_by` (inversas automáticas) y `related`/`duplicate_of`; `Issue.relations` + mutations; validación de ciclos en blocking; filtro por "desbloqueado"; mostrarlas en el detalle y marcar los bloqueados en la lista.

*Origen: leyendo el contrato de `/to-tickets` al configurar las skills (PRB-173).*
