# AUDIT: mapa rápido del modelo de datos frente a Linear

Created by admin.

## Objetivo
Comparar el modelo de entidades y relaciones de prime-board con el modelo público de Linear para identificar diferencias de forma rápida y trazable.

## Alcance
- Workspace, Team, Actor/membership y API keys como contexto de identidad.
- Issue, estados, labels, proyectos, milestones y cycles.
- Views/filtros, Inbox, Reviews, relaciones y jerarquía.
- Relaciones cardinales, ownership, archivado y referencias entre entidades.
- No implementar cambios en este ticket.

## Evidencia requerida
- Mapa resumido de entidades y relaciones actuales de prime-board.
- Correspondencias y ausencias frente al modelo documentado de Linear.
- Diferencias relevantes, sin asumir que toda diferencia sea un bug.
- Links a schema/código/docs consultados.

## Criterios de aceptación
- [ ] El mapa cubre las entidades principales de ambos modelos.
- [ ] Las relaciones se expresan con dirección y cardinalidad cuando sea relevante.
- [ ] Los gaps quedan clasificados como paridad, divergencia intencional o pendiente de decisión.
- [ ] Se deja un comentario final con conclusiones y próximos pasos.
