# Persistir la trazabilidad de origen de las entidades migradas

## Objetivo

Conservar la correspondencia entre cada entidad importada y su identificador original de Linear para poder auditar, reejecutar y reconciliar la migración sin depender de nombres ambiguos.

## Alcance

Definir y persistir el mapa de origen para issues, actores, teams, workflow states, labels, proyectos, milestones, comentarios y relaciones. Conservar URL e identificador de Linear cuando corresponda, sin exportar API keys ni secretos de webhooks.

## Aceptación

* El mapa es estable entre exportaciones y rebuilds.
* Los nombres duplicados no producen asociaciones silenciosas.
* El importador puede detectar entidades ya migradas y cambios posteriores.
* La trazabilidad queda disponible para auditoría y no expone credenciales.
