# Aislar API keys por grant y Membership efectiva

Created by admin.

## Hallazgo
`Actor.apiKeys` lista todas las keys del Actor sin filtrar por grant del Workspace (`apps/server/src/graphql/resolvers.ts:554-562`). Además `apiKeyCreate` valida el Actor globalmente y no exige Membership efectiva (`apps/server/src/domain/actors.ts:271-278`, `apps/server/src/graphql/resolvers.ts:1446-1458`). Puede exponer keys de otro Workspace o crear una key inutilizable para el Workspace actual.

## Criterios de aceptación
- Una consulta de API keys devuelve solo keys autorizadas para el Workspace efectivo.
- Crear una key requiere Actor y Membership válida en ese Workspace.
- Los límites de Team no cruzan Workspaces.
- Hay pruebas con dos Workspaces y actores con Membership distinta.
