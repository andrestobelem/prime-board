# UI: mejorar Inbox y My issues para seguimiento del actor

Created by admin.

## Contexto
Inbox y My issues existen, pero la comparación con Linear muestra que son superficies clave para seguimiento del actor y handoff. Hoy Inbox tiene listado fijo de 50, acciones básicas y fecha simple; My issues tiene filtros limitados.

## Comportamiento esperado
Un actor humano o agente debe poder encontrar rápidamente eventos no leídos y su cola de trabajo, con deep-links estables y acciones recuperables.

## Criterios de aceptación
- [ ] Mostrar unread count/estado visual y refresco después de marcar leído/archivar.
- [ ] Agregar búsqueda/filtros rápidos por issue, tipo, team, project y priority.
- [ ] Agregar navegación por teclado básica (`G-I`, `J/K`, `U`) o documentar equivalentes propios.
- [ ] Ampliar My issues a assigned/created/subscribed cuando el modelo lo soporte; no reemplazar webhooks como canal de agentes.
- [ ] Mantener snooze/reminders y Pulse fuera de alcance salvo decisión posterior.
