# MCP server con tools espejo de Linear

Servidor MCP por stdio, cliente de la API GraphQL, con tools nombradas como las del MCP de Linear: `list_issues`, `get_issue`, `save_issue`, `list_comments`, `save_comment`, `list_projects`, `get_project`, `save_project`, `list_teams`, `get_team`, `list_issue_statuses`, `list_issue_labels`, `list_users`, `get_workspace`.

**Entregable:** un agente que sabe usar el MCP de Linear opera prime-board sin cambios. Spec de referencia: [`docs/specs/mvp.md`](<https://github.com/andrestobelem/prime-board/blob/main/docs/specs/mvp.md>).
