# Definir contrato async de persistencia

Created by admin.

## What to build
Establecer una interfaz de persistencia asíncrona que desacople el dominio del driver y normalice lecturas, escrituras, transacciones, errores y cierre de conexiones.

## Acceptance criteria
- [ ] Existe un contrato único para obtener una fila, listar filas, ejecutar comandos y abrir transacciones.
- [ ] La interfaz expone resultados consistentes para filas afectadas, `RETURNING`, errores y cierre.
- [ ] Incluye pruebas de commit, rollback y propagación de errores.

- None — puede comenzar inmediatamente.
