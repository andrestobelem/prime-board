# Pre-commit: los tests del CLI chocan con un server en el puerto 3394

Created by admin.

## Evidencia
El hook de pre-commit ejecuta `bun test`. `apps/cli/test/cli.test.ts` inicia un server temporal en el puerto fijo `3394`, pero otra instancia aislada de prime-board ya ocupa ese puerto. Los tests del CLI reciben `UNAUTHORIZED` y fallan antes de probar el comportamiento esperado.

## Comportamiento esperado
Los tests del CLI deben usar un puerto temporal libre o aislarse de otros servers locales. El resultado no debe depender de qué proyectos estén activos en la máquina.

## Criterios de aceptación
- El test no colisiona con un server existente en `3394`.
- La prueba conserva su autenticación contra la DB temporal.
- El hook de pre-commit pasa con otras instancias locales activas.
- No se detienen procesos de otros proyectos como efecto lateral.
