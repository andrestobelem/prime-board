# PostgreSQL bootstrap: conservar descripciones de workflow

Created by admin.

## Hallazgo

El bootstrap PostgreSQL de una instalación nueva omite `workflow_states.description` al insertar los estados default. `DEFAULT_WORKFLOW` ya contiene las descripciones y SQLite las persiste mediante `seedTeamWorkflow`.

## Impacto

Una instalación PostgreSQL nueva queda con descripciones `NULL`, mientras SQLite conserva los defaults en inglés. Esto incumple el contrato de defaults y la paridad entre backends.

## Evidencia

- `apps/server/src/db/postgres/bootstrap.ts:50-53` no incluye `description` en el INSERT.
- `apps/server/src/db/defaults.ts` define las descripciones.
- `apps/server/src/db/seed.ts` sí las inserta para SQLite.

## Aceptación

- [ ] Incluir `description` en el INSERT de bootstrap PostgreSQL.
- [ ] Agregar regresión de bootstrap PostgreSQL.
- [ ] Comparar los estados default entre SQLite y PostgreSQL.
