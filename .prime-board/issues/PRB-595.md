# Account Profile: completar avatar de Actor

Created by admin.

## Objetivo
Completar el vertical Profile de un Actor sin convertirlo en User ni mezclarlo con Workspace Membership o Team Membership.

## Alcance
- Exponer `avatarUrl` en Actor.
- Permitir que el Actor edite su avatar; un Workspace Admin puede editar el perfil de otro Actor mediante el control existente.
- Mantener `name`, `email` y `actorLeave` existentes.
- Conservar el avatar en `actors.json` y en rebuild.
- Mostrar y editar el avatar desde Members.

## Criterios de aceptación
- `avatarUrl` acepta una URL HTTP(S) absoluta, permite limpiar con `null` y rechaza valores inválidos o mayores de 2048 caracteres.
- La autorización mantiene el modelo self/admin y la frontera de Workspace existente.
- Export/rebuild conserva el avatar y los exports antiguos sin avatar siguen funcionando.
- La UI usa el campo sin reimplementar `actorLeave`.
- Hay regresiones de API, ACL, URL segura y round-trip.

Las preferencias personales, home view, formato, editor y auto-assign pertenecen a PRB-382. Este child no crea otro modelo de preferencias.
