# Triage: configurar responsabilidad, routing y prioridad requerida

Created by admin.

## Objetivo
Agregar settings de Triage por Team: habilitación, responsable, reglas de routing y requisito de prioridad, integrados con la bandeja existente.

## Contexto
Gap identificado en `docs/research/linear-settings-parity.md` (PRB-376), categoría P1.

## Criterios de aceptación
- Un issue entrante sigue reglas deterministas de routing; la UI y API explican la configuración efectiva y hay pruebas.
- La implementación debe conservar el modelo local-first, single-tenant y API-first de prime-board.
- Agregar regresiones y evidencia en este issue antes de cerrarlo.

## Revalidación contra Linear actual (2026-08-22)

### Ajustes de alcance

- Linear confirma Triage responsibility, Triage Rules, Triage Intelligence y el requisito de prioridad.
- Triage Rules y Triage responsibility están documentados como funciones Business/Enterprise. Triage Intelligence tiene el mismo límite de plan.

### Criterios adicionales

- Las reglas se evalúan en orden y los conflictos quedan visibles.
- Una regla puede actualizar Team, status, assignee, label, project y priority.
- La configuración puede exigir priority antes de aceptar una issue fuera de Triage.
- Se documenta el origen de las issues que entran en Triage y que un template default puede cambiar el status inicial.
- Si prime-board habilita estas funciones en otros planes por su modelo local-first, se registra como divergencia intencional.
