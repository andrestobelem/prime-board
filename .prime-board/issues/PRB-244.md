# Rebuild: preservar referencias de filtros en saved views

Created by admin.

## Origen

Detectado al preparar la réplica operativa en PRB-242, durante la auditoría PRB-228.

## Evidencia

El export actual genera `meta/saved-views.json` con filtros que contienen UUIDs internos, por ejemplo:

```json
{"filter":{"team":{"eq":"01a00a56-..."}}}
```

`rebuildFromRepo` restaura ese JSON sin traducir IDs a los nuevos IDs de la DB. Después de un rebuild, la vista guardada conserva un filtro que ya no coincide con ningún team/issue.

## Comportamiento esperado

Los filtros persistidos en el repo deben usar referencias naturales estables o traducirse durante export/import, igual que Activity y los demás metadatos.

## Criterios de aceptación

- [ ] Export de saved views no contiene IDs internos de teams, states, actors, projects, milestones, labels o issues.
- [ ] Rebuild restaura filtros funcionales, incluyendo filtros de team/proyecto/estado/assignee/labels.
- [ ] Test de round-trip con una vista guardada y filtros no triviales.
- [ ] Exports existentes reciben compatibilidad o un error diagnóstico.
