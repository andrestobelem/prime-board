# Frontend: mostrar Favorites por Actor en el sidebar

Created by admin.

## Hallazgo reproducible

La referencia muestra un bloque `Favorites` entre los recursos del workspace y los teams. El sidebar actual no tiene esa sección ni acciones para fijar/desfijar un proyecto o una vista.

## Comportamiento esperado

El sidebar debe mostrar los favoritos del Actor autenticado, en el orden persistido por la API, con navegación al recurso y una acción clara para quitarlo. La sección no debe mostrar favoritos de otros actores.

## Dependencia

Bloqueado por PRB-268 (relación persistida y API de favoritos).

## Criterios de aceptación

- [ ] Se muestra `Favorites` solo cuando corresponde y se puede colapsar.
- [ ] Proyectos y vistas favoritos se renderizan con icono, nombre y deep-link estable.
- [ ] Agregar, quitar y reordenar actualiza el sidebar sin recargar la aplicación.
- [ ] Un actor no ve favoritos de otro actor.
- [ ] El estado vacío tiene una acción o explicación útil y funciona en viewport móvil.
