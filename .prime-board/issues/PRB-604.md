# Export API/JSON y CSV autenticado

Created by ghostty-scout.

## Hallazgo
PRB-392 necesita separar audit log, export CSV y export API/JSON. El repositorio ya tiene `exportBoard` para la réplica local Markdown/JSON, pero no tiene una superficie operativa para exportar el Workspace como CSV ni un contrato de export JSON/API autenticado.

## Evidencia
- `apps/server/src/export/exporter.ts` escribe `.prime-board/meta/*.json` y logs de issues, no un CSV de issues/members.
- `apps/server/src/server.ts` solo expone GraphQL, health, config y archivos estáticos.
- `apps/cli/src/index.ts` no tiene comando de export de datos operativos.

## Alcance propuesto
Definir una superficie API-first autenticada para export JSON y CSV, con permisos de Workspace Admin, alcance de Workspace/Teams, referencias estables y exclusión de API keys, tokens, hashes, webhook secrets y credenciales. Reutilizar `exportBoard` donde corresponda sin editar `.prime-board/` a mano.

## Relación
Bloquea la entrega completa de PRB-392, pero se mantiene separado del audit log persistente.
