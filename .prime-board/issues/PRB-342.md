# Team Settings: ocultar acciones de labels workspace para owners de team

Created by admin.

## Hallazgo reproducible

`TeamSettingsView` muestra labels de workspace junto con labels del team. Para un team owner, los controles de editar/borrar aparecen activos, pero la API reserva esas mutaciones al workspace admin. También puede mostrarse el formulario para crear labels workspace, que falla al enviarse.

## Comportamiento esperado

Los owners de team deben administrar solo labels de su team; los labels workspace se muestran como solo lectura. Los controles workspace quedan reservados al workspace admin.

## Criterios de aceptación

- Owner de team no ve acciones de escritura para labels workspace.
- Workspace admin conserva acciones sobre labels workspace.
- La creación desde Team Settings siempre usa el team actual para owners.
- Agregar regresiones de permisos/presentación.
