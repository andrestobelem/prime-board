## Objetivo
Recrear tres sesiones de Prime Agent en splits a la derecha de Ghostty y asociarlas con Actors existentes del Team PRB.

- Mantener los Actors `Scout`, `Builder` y `ghostty-scout`.
- Verificar sus API keys contra la instancia local de prime-board.
- Crear una key nueva de lectura/escritura solo para `ghostty-scout` si la key anterior no permite leer.
- Lanzar una sesión por Actor en Ghostty, sin editar código del repositorio.

## Criterios de aceptación
- Cada sesión muestra su identidad correcta con `pb auth status`.
- Las tres sesiones quedan activas en splits a la derecha.
- Las memberships existentes del Team `PRB` no cambian.
- Las claves quedan fuera del repositorio.
