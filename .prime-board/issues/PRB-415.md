# GraphQL: exponer lifecycle, listado y selección de Workspaces sin romper clientes

Created by admin.

## Objetivo
Coordinar el contrato GraphQL para listar, crear y seleccionar Workspaces sin romper clientes legacy.

## Hitos
- `PRB-478`: listado, selección y lifecycle de Workspace.
- `PRB-479`: tipos GraphQL y compatibilidad de clientes legacy.

## Criterios de aceptación
- Ambos hijos están `Done` y la introspection refleja inputs, payloads y errores estables.
- El segundo Workspace no copia recursos fuera del bootstrap definido.
- Requests legacy siguen operando contra el Workspace único/default.
- CLI, MCP y UI pueden consumir el mismo contrato sin autorizar por un input arbitrario.

## Seam de validación
SDL, introspection, resolvers GraphQL y contract tests single/multi-Workspace.

## Dependencias
Requiere `PRB-413` y `PRB-414`.
