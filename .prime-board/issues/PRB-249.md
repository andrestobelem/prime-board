# Frontend: la lista de issues carece de toolbar de filtros y selección

Created by admin.

## Divergencia

La lista de team de prime-board (`/#/team/PRB`) solo muestra el selector de agrupación y las filas. No ofrece un toolbar de `Filter`, búsqueda/orden/display ni selección múltiple con acciones bulk. Los filtros existen en GraphQL y hay vistas guardadas, pero el recorrido visual no permite construir o ajustar una consulta desde la lista.

## Evidencia

- Captura local: `/tmp/pb-home.png` (viewport 1440×1000).
- `apps/web/src/views/TeamView.tsx` renderiza `IssueList` sin controles de filtro/selección.
- Referencia oficial de Linear: [Select issues](https://linear.app/docs/select-issues), cuya captura muestra toolbar de Filter y selección de múltiples issues.

## Comportamiento esperado

La lista debe ofrecer controles visibles para filtrar/ordenar/ajustar la vista y seleccionar issues para acciones compatibles, sin quitar los atajos ni la API existentes.

## Criterios de aceptación

- [ ] La lista de team muestra un control `Filter` que permite combinar filtros soportados por la API.
- [ ] La lista permite seleccionar múltiples issues y expone solo acciones implementadas y autorizadas.
- [ ] El estado de filtros/orden/display es visible y se conserva al navegar o recargar cuando corresponda.
- [ ] Loading, error y empty states siguen funcionando.
