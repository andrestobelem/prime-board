# Docs: alinear fuentes normativas con el runtime actual

## Objetivo

Alinear las fuentes normativas restantes con el estado actual del runtime y evitar que los agentes usen contratos históricos como vigentes.

## Evidencia

- `CONTEXT.md:8,12,26` todavía describe una instalación single-Workspace y un selector futuro, aunque SQLite ya expone selección y aislamiento incremental.
- `docs/adr/0001-bun-typescript-sqlite.md:5-11` todavía afirma SQLite puro y no PostgreSQL, mientras el runtime ofrece PostgreSQL opcional y `ADR-0019` documenta la arquitectura objetivo.
