# Web: mostrar Favorites con capitalización normal

Created by admin.

## Hallazgo reproducible

En el sidebar, la sección `Favorites` se muestra como `FAVORITES`. El texto usa mayúsculas completas y destaca de forma desproporcionada frente a `Teams`, `Inbox`, `Projects`, `Initiatives` y `Views`.

## Evidencia

- `apps/web/src/components/Sidebar.tsx:266-275` renderiza el encabezado `Favorites`.
- `apps/web/src/styles.css:437-442` aplica `text-transform: uppercase` a `.favorites-heading`.
- La sección fue introducida en `fc207537`.

## Comportamiento esperado

El sidebar muestra `Favorites` en capitalización normal (`Favorites`), sin transformar el texto a mayúsculas. El encabezado conserva su jerarquía visual compacta.

## Criterios de aceptación

- [ ] `Favorites` se muestra como `Favorites` en el sidebar.
- [ ] El encabezado conserva color, tamaño, espaciado, foco y estado expandido/colapsado.
- [ ] Otros encabezados del sidebar no cambian.
- [ ] Hay una regresión de UI o una verificación reproducible del texto renderizado.
- [ ] Pasan la suite web, typecheck, build y Prettier.

## Fuera de alcance

No cambiar la escala tipográfica general de la UI ni el modelo de Favorites. PRB-557 cubre la escala; este issue cubre solo la capitalización del encabezado.
