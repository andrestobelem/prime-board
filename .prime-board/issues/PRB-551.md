# Corrige URL pública de Documents con puerto dinámico

Created by admin.

El test real `apps/server/src/graphql/postgres-documents.test.ts` contra Podman falla porque `Document.url` devuelve `http://localhost:0/document/<id>` cuando `createApp` usa `port: 0`; el servidor escucha en un puerto asignado.

Evidencia: PostgreSQL 17 real, PRB-550 coverage worktree `221621d`/`551885f`: el Document se crea correctamente y conserva Issue link, pero la URL expuesta usa puerto 0.

Criterios de aceptación:
- `Document.url` usa el puerto/base URL efectivo del servidor.
- La URL es correcta con puerto explícito y con `port: 0`.
- SQLite y PostgreSQL conservan el mismo contrato.
- El test real de Documents pasa contra Podman sin relajar la aserción.
