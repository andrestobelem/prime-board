# UI: vistas guardadas para equipos y workspace

Created by admin.

Referencia Linear desktop: el sidebar ofrece `Views` tanto a nivel workspace como team.

## Objetivo

Permitir guardar filtros y ordenamientos como vistas reutilizables y compartirlas con el workspace o team.

## Criterios de aceptación

- Crear, editar, duplicar, archivar y eliminar una vista guardada.
- Persistir filtros, orden, agrupación y columnas visibles.
- Distinguir vistas personales, de team y de workspace.
- Abrir una vista desde el sidebar y compartir un enlace estable.
