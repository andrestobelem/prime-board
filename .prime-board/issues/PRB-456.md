# Artefacto completo: web, migraciones, WAL y Repository Replica

Created by admin.

## What to build
El artefacto distribuido completo debe servir la UI, aplicar migraciones y WAL, ejecutar una mutación observable y reflejarla en la Repository Replica sin necesitar el checkout del monorepo.

## Acceptance criteria
- [ ] La UI se sirve desde el artefacto y sus assets cargan correctamente.
- [ ] Una DB nueva aplica todas las migraciones y activa WAL/foreign keys.
- [ ] Una escritura autenticada cambia el Operational State y actualiza la réplica.
- [ ] Reabrir la DB conserva los datos y la réplica sigue siendo legible.
- [ ] El smoke test no depende de rutas del checkout de desarrollo.

## Test seam
HTTP UI + GraphQL mutation + filesystem replica + reopen de DB.
