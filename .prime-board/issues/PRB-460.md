# Transporte MCP Streamable HTTP

Created by admin.

## What to build
Un endpoint MCP Streamable HTTP local que reutilice el catálogo y handlers actuales, mantenga el transporte stdio existente y permita initialize/list/call autenticados.

## Acceptance criteria
- [ ] `/mcp` soporta initialize, list tools y call tool sobre HTTP.
- [ ] Bearer auth se valida antes de ejecutar una tool y los errores conservan códigos estables.
- [ ] `list_issues`, `save_issue`, `save_comment` y operaciones de Workspace llegan a GraphQL como autoridad.
- [ ] El transporte stdio actual sigue funcionando sin regresiones.
- [ ] Las sesiones concurrentes no comparten credenciales ni contexto accidentalmente.

## Test seam
Cliente MCP HTTP + initialize/list/call + GraphQL + stdio regression.

None — can start immediately.
