# UI: renderizar columnas Project y Cycle en Board según Display Options

Created by admin.

## Hallazgo reproducible

`DisplayOptions.tsx:4-11` ofrece `project` y `cycle` y App persiste/pasa esas opciones, pero `BoardView.tsx:482-490` solo renderiza priority/labels/assignee. `IssueList.tsx:262-267` sí implementa project/cycle, por lo que activar esas columnas no tiene efecto en Board (incluido project board).

## Comportamiento esperado

Las opciones visibles deben tener efecto consistente en Board: activar Project o Cycle debe mostrar la información correspondiente en cada card y desactivarla debe ocultarla.

## Criterios de aceptación

- Board de team y de project renderiza Project y Cycle cuando están activados.
- Las cards manejan issue sin project/cycle sin romper layout y muestran estado vacío coherente.
- La configuración persiste al navegar/recargar y coincide con List.
- Se agregan pruebas de render para las combinaciones relevantes.

## Duplicados/relación

PRB-280 (Done) amplió Display Options y menciona project board, pero dejó sin implementar el render de estas columnas; es un residual verificable, no un duplicado exacto.
