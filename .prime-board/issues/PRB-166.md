# Repo sync: escribir solo lo que cambió

`createRepoSync` regenera el export **completo** en cada mutación (108 archivos hoy). Con 50 issues es imperceptible, pero no escala: con miles de issues cada comentario reescribiría todo el directorio.

Propuesta: sync incremental — reescribir solo el issue afectado (`issues/<ID>.json` + append a `log/<ID>.jsonl`) y los archivos de `meta/` solo cuando cambia metadata. El append al log ya es naturalmente incremental.
