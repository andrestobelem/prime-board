# Docs: reemplazar enlaces operativos de Linear por referencias locales

Created by admin.

## Hallazgo

La documentación operativa todavía enlaza tickets históricos AT-* a `linear.app`, aunque esos issues están importados y disponibles en la réplica local `.prime-board/issues/`.

## Alcance acordado

Actualizar únicamente enlaces operativos de documentos del proyecto a referencias locales de prime-board. Conservar referencias externas de auditoría comparativa y exports históricos para mantener trazabilidad.

- `docs/alcance-mvp.md`, `docs/guia-agentes.md`, `docs/relevamiento-linear.md` y `docs/specs/mvp.md` enlazan snapshots locales.
- Auditorías y migraciones históricas no se modifican.
- No quedan enlaces `linear.app/andrestobelem/issue` en documentación operativa.
