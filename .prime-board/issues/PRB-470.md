# Launcher: reservar el puerto implícito de forma atómica

Created by admin.

## Objetivo
Eliminar la carrera entre detectar un puerto loopback libre y hacer spawn del servidor del launcher.

## Criterios de aceptación
- Dos proyectos distintos iniciados en paralelo nunca eligen el mismo puerto.
- Un segundo proceso reintenta o falla de forma explícita si pierde la reserva.
- Un puerto explícito ocupado conserva el error existente.
- La prueba cubre concurrencia, limpieza tras fallo de arranque y ausencia de contaminación entre proyectos.
