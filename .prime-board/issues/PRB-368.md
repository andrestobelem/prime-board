# Integración: usar prime-board como instancia aislada en proyectos externos

Created by admin.

## Objetivo

Permitir que un proyecto externo use una instancia aislada de prime-board con una réplica `.prime-board/` propia y una skill instalable para agentes.

## Alcance

- Skill `prime-board-workflow` distribuible en proyectos consumidores.
- Script de bootstrap para DB, puerto, réplica y credenciales.
- Documentación de instalación, MCP y CLI.

## Criterios de aceptación

- Un clon de prime-board puede inicializar una instancia para otro repo sin editar archivos internos.
- El proyecto consumidor tiene instrucciones de issue tracking accionables.
- DB, puerto y `PRIME_BOARD_REPO` quedan aislados por proyecto.
- Validar el flujo con shellcheck o ejecución controlada y actualizar README.
