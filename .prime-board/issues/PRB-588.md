# Web: evitar clipping del popup de Workspace al contener el Sidebar

Created by Builder.

## Hallazgo reproducible

El nuevo contenedor scrollable del Sidebar usa `overflow-x: hidden`. El popup del selector de Workspace vive dentro de ese contenedor y puede recortar nombres o `urlKey` largos en vez de permitir que el popup se muestre completo.

## Evidencia

- `apps/web/src/styles.css:264-265` aplica `overflow-x: hidden` al contenedor del Sidebar.
- `apps/web/src/components/Sidebar.tsx:184-200` renderiza el selector y su popup dentro de esa jerarquía.
- Revisión independiente de `ad8754c`: el clipping no está cubierto por la suite web.

## Comportamiento esperado

El Sidebar debe contener el overflow de sus recursos sin recortar el popup del selector de Workspace. Los nombres y `urlKey` largos deben permanecer visibles o truncarse dentro del control adecuado.

## Criterios de aceptación

- [ ] El selector de Workspace muestra correctamente muchos elementos.
- [ ] Nombres y `urlKey` largos no recortan el popup.
- [ ] El contenido normal del Sidebar continúa sin overflow horizontal.
- [ ] Se añade una regresión automatizada o evidencia manual reproducible para el popup.
