# UI: ofrecer Retry en Workspace Gate y vistas secundarias

Created by admin.

## Objetivo
Permitir recuperar errores transitorios sin recargar la SPA ni abandonar la ruta actual.

## Evidencia
- `apps/web/src/App.tsx` muestra `Workspace unavailable` sin botón Retry cuando falla el Workspace Gate.
- Cycle, Reviews, Initiative, Members, Team Settings e Issue detail muestran errores sin `onRetry` consistente.
- Las queries de metadata de algunas vistas pueden fallar sin una acción visible.

## Criterios de aceptación
- [ ] Workspace Gate ofrece Retry y conserva la ruta seleccionada.
- [ ] Cycle, Reviews, Initiative, Members, Team Settings e Issue detail usan un estado común Error + Retry.
- [ ] Un error de metadata no oculta la acción principal sin explicación.
- [ ] Retry conserva filtros, cursores y borradores cuando sea seguro.
- [ ] Hay regresiones para error inicial y error al cargar una página siguiente.
