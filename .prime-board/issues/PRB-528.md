# Issues: implementar unarchive en API, CLI, MCP y UI

Created by admin.

## Objetivo
Completar el ciclo reversible de archivo de Issues.

## Evidencia
- El schema solo expone `issueArchive` (`packages/schema/src/sdl.ts`).
- `apps/server/src/graphql/issue-resolvers.ts` implementa archive, pero no existe `issueUnarchive`.
- `apps/cli/src/commands/issue.ts` solo expone `issue archive`.
- La auditoría de paridad GraphQL registra `unarchive/delete` como operaciones ausentes.

## Comportamiento esperado
Un actor autorizado puede restaurar una Issue archivada sin cambiar su identidad ni perder su actividad.

## Criterios de aceptación
- [ ] GraphQL expone `issueUnarchive` con el mismo control de acceso y contexto que `issueArchive`.
- [ ] La operación es idempotente y no duplica actividad ni eventos.
- [ ] CLI y MCP exponen la operación con una respuesta estable.
- [ ] La UI ofrece la acción solo para Issues archivadas y actualiza la vista sin recarga completa.
- [ ] Se emite un evento documentado y el export/rebuild conserva `archivedAt`.
- [ ] Hay pruebas SQLite, PostgreSQL si aplica, GraphQL, CLI, MCP y UI.
