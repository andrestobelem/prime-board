# Runtime: empaquetar prime-board como artefacto instalable por Prime Agent

Created by admin.

## Objetivo
Convertir el runtime de prime-board en un artefacto instalable y arrancable por una extensión de prime-agent.

## Alcance
- Eliminar la dependencia de `workspace:*`/paquetes privados para producción o publicar un runtime coordinado.
- Añadir launcher con `--project`, `--db`, `--port`, `--host`, `--web-dist`, `--status` y lock por proyecto.
- Servir solo en loopback por defecto; mantener DB fuera del package y réplica en el repositorio.
- Producir y probar binarios Bun standalone por plataforma o documentar la dependencia explícita de Bun.
- Empaquetar UI/migraciones/assets, señales, health-check, logs y bootstrap de credenciales sin filtrar secretos.

## Criterios de aceptación
- [ ] Una instalación limpia arranca una instancia aislada por repositorio y espera `/health` antes de devolver contexto.
- [ ] Dos sesiones concurrentes no levantan dos procesos ni comparten DB equivocada.
- [ ] UI, migraciones, SQLite WAL y réplica funcionan desde el artefacto distribuido.
- [ ] El server bindea a `127.0.0.1` salvo override explícito y las credenciales quedan fuera del package/replica.
- [ ] Existe matriz de plataformas, checksums y rollback de migraciones documentada.
