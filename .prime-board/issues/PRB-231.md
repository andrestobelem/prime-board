# Auditoría: persistencia, export/rebuild y consistencia de datos

Created by admin.

## Objetivo

Comprobar que la información operativa sobreviva a exportaciones, reconstrucciones y migraciones según el contrato del repositorio.

## Revisar

- migraciones y base SQLite
- logs como fuente de verdad
- snapshots Markdown y archivos `meta`
- export → rebuild → consulta
- relaciones, sub-issues, estados, asignaciones, ciclos, activity y comentarios
- datos que se pierden, duplican o quedan desnormalizados

## Entrega

Documentar round-trips ejecutados, datos comparados y cualquier pérdida o inconsistencia reproducible. No corregir todavía.
