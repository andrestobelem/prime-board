# QA: matriz de migración, réplica, export y rebuild

Created by admin.

## Objetivo
Verificar que el cutover y la Repository Replica mantienen el aislamiento y permiten recuperar datos.

## Criterios de aceptación
- La migración se ejecuta sobre una copia y entrega conteos, checksums y reporte antes del cutover.
- Export/rebuild de A deja intactos los recursos de B y conserva IDs, fechas, relaciones y metadata.
- Exports legacy, namespace multi-Workspace, scope faltante y conflicto incompatible tienen resultados definidos.
- No aparecen API keys ni secretos en snapshots, Logs, metadata o reportes.

## Seam de validación
Migrator, exporter, `rebuild`, RepoSync y round-trip sobre directorios temporales.

## Dependencias
Requiere PRB-412, PRB-416 y PRB-417.
