# Web: agregar feedback y rollback para Favorites

Created by admin.

## Objetivo
Mantener el sidebar coherente cuando falla una mutación de Favorites.

## Evidencia
- `apps/web/src/App.tsx` y `Sidebar.tsx` ejecutan create, delete y reorder sin `catch` local ni Retry.
- Un fallo de red o permisos puede dejar una promesa rechazada sin mensaje operativo.

## Criterios de aceptación
- [ ] Create, delete y reorder muestran estado pending.
- [ ] El error conserva el estado anterior o aplica rollback explícito.
- [ ] El sidebar muestra Retry sin perder la selección actual.
- [ ] Cambio de Workspace no reutiliza favoritos de otro contexto.
- [ ] Hay pruebas de éxito, error y permisos insuficientes.
