# QA: matriz GraphQL de aislamiento multi-Workspace

Created by admin.

## Objetivo
Crear la suite negativa y positiva que demuestre aislamiento en GraphQL.

## Criterios de aceptación
- La matriz cubre roots, nested resolvers, mutations, IDs, keys, nombres, filtros, FTS, paginación y relaciones.
- A y B pueden operar en paralelo con datos homónimos sin leaks.
- Se prueban Actor compartido, roles/status distintos, grants/scopes, key revocada/expirada y selector falsificado.
- Cada fallo registra fixture, operación, resultado esperado y código GraphQL.
- La suite genera un reporte reproducible para PRB-420.

## Seam de validación
Tests GraphQL de integración, fixtures SQLite multi-Workspace y reporte JSON.

## Dependencias
Requiere PRB-412, PRB-413, PRB-414, PRB-415 y PRB-416.
