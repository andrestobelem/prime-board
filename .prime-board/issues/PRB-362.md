# MCP: rechazar type en save_user al actualizar un actor

Created by admin.

## Hallazgo reproducible

`save_user` expone `type` y acepta `save_user(id, type=...)`, pero el update lo ignora silenciosamente porque ActorUpdateInput no admite type.

## Comportamiento esperado

El contrato de update debe rechazar `type` o implementarlo explícitamente; nunca ignorar un campo solicitado.

## Criterios de aceptación

- `type` solo está disponible al crear, o update devuelve VALIDATION_FAILED.
- Regresión MCP.
