# UI: corregir la ruta después de archivar desde Command Palette

Created by admin.

## Objetivo
Conservar un destino válido después de archivar una Issue desde la Command Palette.

## Evidencia
- `apps/web/src/App.tsx:248-255` llama `navigate("/my-issues")` después de `issueArchive`.
- `apps/web/src/router.tsx` reconoce la sección `my`, no la ruta `my-issues`.
- El fallback puede enviar al usuario al Team por defecto y perder el contexto de origen.

## Comportamiento esperado
Una operación exitosa navega a una ruta existente o vuelve al contexto de origen. Una operación fallida conserva la ruta actual y muestra el error.

## Criterios de aceptación
- [ ] El archive desde la Palette navega a `#/my` o a un destino de retorno explícito.
- [ ] Un error de archive no cambia la ruta.
- [ ] La acción muestra un error recuperable.
- [ ] Hay una regresión que verifica la mutación y la ruta final.
