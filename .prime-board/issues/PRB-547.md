# Actualiza smoke PostgreSQL de Teams al schema GraphQL vigente

Created by admin.

El smoke `scripts/validate-postgres-actors.ts` marca `teams=false` contra PostgreSQL real porque espera que consultar `team { labels { id } }` devuelva `VALIDATION_FAILED`. El schema vigente soporta esa relación y devuelve `labels: []` sin error.

Evidencia: Podman + PostgreSQL 17; todas las demás comprobaciones del reporte pasan. El fallo está en la expectativa del smoke, no en el resolver observado.

Criterios de aceptación:
- El smoke usa el contrato GraphQL vigente para `team.labels`.
- La validación de Teams pasa contra PostgreSQL real.
- Se conserva cobertura de autorización y membresías.
- No se relajan checks de acceso.
