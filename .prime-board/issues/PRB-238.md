# MCP: no convertir un parent inválido en null

Created by admin.

## Origen

Auditoría integral PRB-228 / sub-issue PRB-232.

## Evidencia

En `save_issue`, el camino de update hace `input.parentId = parent.issue?.id ?? null`. Una referencia inexistente se interpreta como quitar el parent actual.

## Comportamiento esperado

Una referencia inválida debe devolver `NOT_FOUND`. Quitar el parent debe requerir una entrada explícita que lo solicite.

## Criterios de aceptación

- [ ] Update con parent inexistente no modifica el issue.
- [ ] La tool devuelve un error identificable `NOT_FOUND`.
- [ ] Existe test MCP para parent válido, parent inválido y desparentado explícito.
