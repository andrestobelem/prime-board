# UI: editar agentes y sus nombres operativos

## Objetivo

Permitir editar los agentes desde la interfaz de prime-board, usando nombres humanos/operativos y no el nombre del modelo.

## Criterios de aceptación

- Desde Members/Settings se puede editar el nombre y el email de un actor agente.
- El cambio conserva el ID, las asignaciones, la autoría histórica y las API keys existentes.
- Los nombres son obligatorios y únicos sin distinguir mayúsculas/minúsculas.
- Los agentes históricos retirados (`claude`, `demo-agent`, `Linear`) no se reactivan accidentalmente.
- Se agregan tests de UI/API para editar y validar nombres duplicados.
