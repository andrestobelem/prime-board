# UI: completar el overview de proyectos y milestones

Created by admin.

## Contexto
La pantalla de proyecto actual muestra datos, updates, milestones e issues, pero Linear ofrece un overview editable con propiedades, milestones y tabs/contexto de issues.

## Evidencia
- `apps/web/src/views/ProjectView.tsx` permite postear update y archivar, pero no editar nombre, descripción, estado, lead, fecha objetivo o teams.
- No hay creación/edición/reordenamiento/borrado de milestones desde la pantalla, aunque GraphQL y CLI lo soportan.

## Comportamiento esperado
El proyecto debe ser una unidad usable para encargar y seguir un objetivo de agente sin salir a GraphQL/CLI para tareas cotidianas.

## Criterios de aceptación
- [ ] Separar claramente Overview e Issues y conservar deep-links.
- [ ] Editar propiedades básicas del proyecto con feedback de mutación.
- [ ] Crear, editar, borrar y reordenar milestones; mantener progreso y fechas.
- [ ] Mantener multi-team y filtros por milestone.
- [ ] No incorporar Timeline/Documents/analytics como dependencia de este ticket.
