# Docs: actualizar README y contrato export/rebuild

Created by admin.

## Origen

Auditoría integral PRB-228 / sub-issue PRB-234.

## Evidencia

`README.md` declara 43 tests y 14 tools MCP; actualmente el suite tiene 227 tests y hay 19 tools registradas. ADR-0004 afirma que el importer rechaza exports parciales con `--allow-partial`, pero ese comportamiento no está implementado.

## Criterios de aceptación

- [ ] README refleja comandos, cobertura y cantidad real de tools o evita cifras frágiles.
- [ ] La documentación vigente distingue historial del MVP de contrato actual.
- [ ] ADR-0004, guía de agentes y scripts describen el mismo comportamiento para exports parciales.
- [ ] Ejemplos verificados contra una ejecución real.
