# Launcher por Repository Replica: aislamiento, lock y discovery

Created by admin.

## What to build
Un launcher por repositorio que derive DB y Repository Replica independientes, reutilice el proceso correcto cuando dos sesiones apuntan al mismo proyecto y distinga estado activo, stale o detenido.

## Acceptance criteria
- [ ] `--project` deriva ubicaciones deterministas e independientes para dos repositorios.
- [ ] Dos invocaciones concurrentes del mismo repositorio comparten proceso/DB en vez de arrancar dos instancias.
- [ ] Dos repositorios nunca comparten DB, lock ni réplica.
- [ ] `--status` distingue running, stale y not-running con códigos documentados.
- [ ] Un cierre normal libera el lock y uno abrupto permite detectar/reparar un lock stale sin tocar otra instancia.

## Test seam
Launcher + proceso + `/health` + rutas de DB/réplica + lock.
