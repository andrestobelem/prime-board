# Importar credenciales fuera del Repository Source y reconstruir derivados

Created by admin.

## What to build
Preservar o rotar API keys y secrets de webhooks mediante un canal protegido fuera del Log, y reconstruir las estructuras derivadas de PostgreSQL.

## Acceptance criteria
- [ ] Los hashes/API keys, scopes, expiración, revocación y rotación se migran o regeneran sin aparecer en Git, Logs ni Markdown.
- [ ] Los webhook secrets se conservan mediante un canal protegido y sus firmas siguen siendo válidas, o se rotan con evidencia.
- [ ] Search vectors, índices, checkpoints y metadata derivada se reconstruyen después del replay.
- [ ] La ruta basada solo en `.prime-board/` queda documentada como recuperación de dominio que requiere regenerar credenciales.
- [ ] La API no acepta escrituras de negocio directas en PostgreSQL fuera del projector.

## Blocked by
- PRB-453 — Definir contrato del event log y projector PostgreSQL.
- PRB-431 — Migrar autenticación, API keys e invitaciones.
- PRB-444 — Migrar webhooks y dispatcher.
- PRB-446 — Importar histórico SQLite al event log canónico.
