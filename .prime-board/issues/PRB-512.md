# Aislar labels anidados por Workspace en Team.labels

Created by admin.

## Hallazgo
`Team.labels` devuelve labels de Workspace de otras instancias porque llama a `listLabels(context.db, team.id)` sin aplicar `scopeWorkspaceRows` (`apps/server/src/graphql/resolvers.ts:384-386`). La consulta raíz `labels` sí filtra, pero el campo anidado no.

## Evidencia
Con dos Workspaces, creé el label workspace-scoped `only-in-default` en el Workspace inicial y consulté `teams { labels { name } }` con el segundo Workspace. El label apareció en el segundo Workspace.

## Criterios de aceptación
- `Team.labels` devuelve solo labels del Workspace del contexto.
- Un label de otro Workspace no aparece en campos anidados.
- Hay una prueba de regresión con dos Workspaces.
- La consulta raíz y los campos anidados usan el mismo límite de aislamiento.
