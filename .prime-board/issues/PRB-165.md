# Los eventos del log no alcanzan para reconstruir un issue

Al exportar (PRB-156) quedó claro que el log de actividad es un **historial para la UI**, no un event log completo:

- `created` solo guarda `{title}` — faltan descripción, team, número, prioridad, estado inicial, proyecto, parent.
- `description_changed` guarda `{}` (sin el valor nuevo).

Por eso la Fase 1 exporta **snapshot + log**: el snapshot es hoy la única fuente completa. Para que la Fase 3 (log como fuente de verdad) sea posible, los eventos tienen que ser autosuficientes: `created` con el payload completo y `*_changed` con el valor nuevo.

**Bloquea PRB-158.** Conviene hacerlo junto con PRB-157 (importador), que es donde se va a notar la diferencia.
