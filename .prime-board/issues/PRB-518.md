# Corregir contrato y guía de Workspace

Created by admin.

## Objetivo
Corregir el contrato y la guía de Workspace detectados durante la revisión de PRB-509.

## Hallazgos
- La API usa `UNAUTHORIZED` y `NOT_FOUND` de forma que puede contradecir el contrato documentado.
- El selector de Workspace ya existe en CLI/UI, pero la guía no lo refleja de forma completa.
- El bootstrap de identidad debe distinguirse del seed de datos de demostración.
- La documentación conserva una advertencia histórica del MVP sin indicar su estado actual.
- Hay texto y estilo que no siguen las convenciones técnicas del repositorio.

## Criterios de aceptación
- La guía documenta el código de error esperado para cada caso.
- La guía explica el selector de Workspace disponible en CLI y UI.
- Bootstrap e importación/seed de demo tienen responsabilidades separadas y documentadas.
- La advertencia histórica queda marcada como histórica o se elimina si ya no aplica.
- La documentación pasa las validaciones de estilo y mantiene la terminología del proyecto.
- No se editan archivos generados de `.prime-board` a mano.
