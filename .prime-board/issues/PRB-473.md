# Datos: migrar grants, seed y rollback de Workspace

Created by admin.

## Objetivo
Completar el backfill de credenciales y el bootstrap de Workspaces nuevos.

## Criterios de aceptación
- `api_key_workspaces`, límites por Team e invitaciones tienen `workspace_id` y backfill al Workspace existente.
- Una key legacy recibe un grant al Workspace actual sin exponer ni regenerar su hash.
- Una base sin Workspaces crea el Workspace, Membership admin, Team y Workflow State default una sola vez.
- Crear un Workspace adicional siembra solo sus recursos propios.
- La migración repetida es idempotente y el rollback conserva la base anterior.

## Seam de validación
Migrator SQLite, seed, fixtures de API keys/invitaciones, export de metadata y prueba de rollback en una copia.

## Fuera de alcance
La resolución de `WorkspaceContext` y el contrato GraphQL se implementan en `PRB-413` y `PRB-415`.
