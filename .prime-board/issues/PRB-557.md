# Web: aumentar la escala tipográfica base de la UI

Created by admin.

## Objetivo
Aumentar la escala tipográfica de la UI para mejorar la lectura de listas y navegación.

## Criterios de aceptación
- El texto base y las filas usan 16px.
- Sidebar y navegación usan 16px.
- Botones, filtros e inputs usan 15px.
- Identificadores y metadatos principales usan 14px.
- Los labels compactos conservan 11px cuando cumplen una función secundaria.
- Los títulos mantienen su jerarquía visual existente.
- La pantalla mantiene su densidad, responsive y accesibilidad.
- La suite Web y el build siguen pasando.
