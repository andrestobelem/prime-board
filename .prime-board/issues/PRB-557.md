# Web: aumentar la escala tipográfica base de la UI

Created by admin.

## Objetivo
Aumentar ligeramente la escala tipográfica de la UI para mejorar la lectura de listas y navegación.

## Criterios de aceptación
- El texto base y las filas usan 14px.
- Sidebar y navegación usan 14px.
- Botones, filtros e inputs usan 13px.
- Identificadores y metadatos usan 12px.
- Los labels compactos conservan 11px cuando cumplen una función secundaria.
- La pantalla mantiene su densidad, responsive y accesibilidad.
- La suite Web y el build siguen pasando.
