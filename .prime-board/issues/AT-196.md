# rebuild falla sobre un índice poblado por la FK default_state_id

`bun run rebuild` falla con `FOREIGN KEY constraint failed` cuando reconstruye una DB que ya contiene teams: la columna teams.default_state_id referencia workflow_states y el importador intenta borrar los estados antes de los teams. Debe poder reconstruir un índice existente con foreign keys activadas.
