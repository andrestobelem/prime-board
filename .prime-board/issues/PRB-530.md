# UI: normalizar dialogs, menús y landmarks accesibles

Created by admin.

## Objetivo
Aplicar un patrón accesible y consistente a dialogs, menús, popovers y landmarks del shell.

## Evidencia
- `apps/web/src/components/Palette.tsx` no declara un dialog accesible.
- `QuickCreate` y `EntityModal` no tienen focus trap completo.
- Members, IssueActionMenu y el filter popover no cierran de forma uniforme con Escape o click externo.
- `apps/web/src/App.tsx` usa `div` para el contenido principal y `Sidebar.tsx` no nombra el `nav`.
- `PRB-281` está `Done`, pero estos residuos siguen en el checkout actual.

## Criterios de aceptación
- [ ] Cada dialog tiene nombre accesible, `role="dialog"`, `aria-modal` y foco inicial.
- [ ] Tab queda dentro del overlay y el foco vuelve al trigger al cerrar.
- [ ] Escape y click externo tienen una regla consistente; un submit no se puede cerrar accidentalmente.
- [ ] Menús y popovers tienen roles, nombres y cierre accesibles.
- [ ] El shell usa landmarks (`nav`, `main`) nombrados y un skip link.
- [ ] Hay pruebas de teclado, foco y dark/light.
