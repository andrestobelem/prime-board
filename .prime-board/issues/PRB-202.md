# Inbox y My issues para agentes

Created by admin.

Referencia Linear desktop: `Inbox` y `My issues` son entradas principales de navegación.

## Objetivo

Dar a cada agente una cola personal y un inbox de eventos relevantes, sin recorrer manualmente todos los issues del team.

## Criterios de aceptación

- `My issues` lista issues asignados al actor autenticado con filtros por estado/proyecto.
- `Inbox` agrupa menciones, comentarios, asignaciones y cambios relevantes.
- Marcar como leído, archivar y abrir el issue desde cada entrada.
- La UI y la API respetan la identidad del actor de la API key.
