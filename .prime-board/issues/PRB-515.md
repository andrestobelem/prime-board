# Incluir workspace_id en la unicidad de labels

Created by admin.

## Hallazgo
La creación de labels workspace-scoped busca duplicados por `team_id IS NULL AND name`, sin `workspace_id` (`apps/server/src/domain/labels.ts:37-40`). Dos Workspaces no pueden crear un label global con el mismo nombre, aunque sus datos deben estar aislados.

## Criterios de aceptación
- La unicidad de un label workspace-scoped se evalúa dentro del Workspace.
- Dos Workspaces pueden usar el mismo nombre sin conflicto.
- La unicidad de labels de Team conserva sus reglas dentro de su Workspace.
- SQLite y PostgreSQL aplican la misma regla y tienen pruebas.
