# Crear harness de integración PostgreSQL

Created by admin.

## What to build
Crear un harness de tests aislados contra PostgreSQL en Podman que pueda ejecutar la suite de integración sin compartir estado entre casos.

## Acceptance criteria
- [ ] El harness espera readiness, inicializa el esquema y limpia o aísla cada ejecución.
- [ ] Tests paralelos no comparten datos accidentalmente.
- [ ] El comando de integración documenta setup, teardown y diagnóstico del contenedor.
- [ ] Un test de migración y un test GraphQL end-to-end pasan contra PostgreSQL.

## Blocked by
- Validar Bun.SQL para PostgreSQL.
- Levantar PostgreSQL reproducible con Podman.
- Crear baseline PostgreSQL.
- Crear migrator PostgreSQL con lock y checksums.
