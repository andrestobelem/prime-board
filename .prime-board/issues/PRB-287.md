# UI: pulir workflow states y creación rápida de issues

Created by admin.

## Objetivo
Revisar y acercar a Linear las pantallas de configuración de workflow/labels y el flujo de creación rápida de issues, priorizando claridad visual, descubrimiento y feedback sin ampliar el modelo single-workspace.

## Evidencia
- `apps/web/src/views/TeamSettingsView.tsx` concentra states y labels en filas con estilos inline, sin paneles/secciones visuales claras ni feedback homogéneo de mutaciones.
- `apps/web/src/components/QuickCreate.tsx` permite crear con `C`, pero no hay CTA visible persistente y sus campos select no tienen labels explícitos.
- La referencia de Linear muestra páginas de settings agrupadas por secciones, filas compactas, estados/colores distinguibles, botones `+` contextuales y un composer de issue con jerarquía clara.

## Alcance
- Pulir estados del workflow, labels, default state, orden y eliminación.
- Mejorar el composer de creación rápida: CTA visible, labels accesibles, estados de envío/error y jerarquía visual.
- No agregar multi-workspace, templates, Documents ni campos fuera del contrato actual.

## Criterios de aceptación
- [ ] Workflow states y labels se muestran en paneles consistentes, con encabezado, descripción, acción `Add` contextual y filas legibles en dark/light/mobile.
- [ ] Las acciones de state/label muestran saving/error y no dejan cambios silenciosamente fallidos.
- [ ] La página conserva el default state visible y permite ordenar/eliminar con confirmación cuando corresponda.
- [ ] Existe un CTA visible `New issue` además de `C`/`Cmd+K`.
- [ ] QuickCreate tiene labels/aria para team, title, description, priority y assignee, y feedback de carga/error sin perder el borrador.
- [ ] Se mantiene el flujo GraphQL/API-first y se agregan regresiones de presentación/derivación donde sea testeable.
