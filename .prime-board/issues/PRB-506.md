# Pre-commit: bun test descubre worktrees ignoradas bajo scratchpad

Created by admin.

## Hallazgo

El hook `.husky/pre-commit` ejecuta `bun test` sin rutas. Bun recorre también `scratchpad/worktrees/*`, aunque `scratchpad/` esté ignorado por Git.

En la validación del ciclo se ejecutaron 2187 tests y fallaron 97. Las copias de `apps/cli/test/cli.test.ts` de las worktrees aún usan el puerto fijo `3394`; al ejecutarse junto con otras copias, reciben `UNAUTHORIZED` o quedan en timeout. También se repiten las pruebas del launcher.

La suite explícita de las rutas del producto (`apps/server apps/web apps/mcp packages scripts` y el test CLI actualizado) pasa.

## Comportamiento esperado

El hook debe ejecutar solo tests versionados del producto y no debe descubrir worktrees o scratchpad temporales.

## Criterios de aceptación

- [ ] El hook excluye `scratchpad/` y sus worktrees.
- [ ] Incluye los tests versionados de server, web, MCP, packages, scripts y CLI.
- [ ] `bun run typecheck` y el hook pasan con worktrees presentes.
- [ ] El hook no requiere borrar worktrees ni detener procesos externos.
