# Corrige la conexión GraphQL de Reviews en PostgreSQL

Created by admin.

## Evidencia

La validación real con Podman y PostgreSQL 17 mostró un error en `apps/server/src/graphql/resolvers.ts`: el resolver PostgreSQL de `reviews` retorna `visible.map(mapPostgresReview)`, pero el schema público exige `ReviewConnection` con `nodes` y `pageInfo`.

Con una consulta válida `reviews { nodes { id status } }`, `openOnly` y un `reviewerId` inexistente devuelven `Cannot return null for non-nullable field ReviewConnection.nodes`.

El mismo smoke también reveló que `scripts/validate-postgres-reviews.ts` usa el shape antiguo y debe alinearse con `nodes`; esa actualización debe acompañar la cobertura del resolver.

## Criterios de aceptación

- El resolver PostgreSQL devuelve siempre `nodes` y `pageInfo`.
- `first`, `openOnly`, `reviewerId`, `teamId`, `projectId`, `olderThanDays` y cursores conservan el contrato SQLite/GraphQL.
- Las consultas vacías y filtros sin resultados devuelven `nodes: []`, sin errores GraphQL.
- El smoke real de Reviews pasa contra PostgreSQL con Podman.
- La cobertura SQLite y PostgreSQL mantiene autorización equivalente.
