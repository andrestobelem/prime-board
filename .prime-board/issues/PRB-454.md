# Runtime distribuible: instalación limpia y arranque autenticado

Created by admin.

## What to build
Un artefacto de runtime elegido explícitamente para v0 (fuente con versión Bun fijada o binario; no ambos implícitamente) que una instalación limpia pueda arrancar en un proyecto temporal, responder `/health` y ejecutar una operación GraphQL autenticada sin depender de `workspace:*` ni paquetes privados de producción.

## Acceptance criteria
- [ ] El artefacto se instala en un entorno limpio con solo sus dependencias de producción documentadas.
- [ ] Arranca para un repositorio temporal y responde `/health`.
- [ ] La API GraphQL acepta una operación autenticada y rechaza una sin bearer.
- [ ] El contrato de distribución, runtime requerido y códigos de salida están documentados.

## Test seam
Comando/artefacto instalado + `/health` + una query/mutation GraphQL autenticada.

## Blocked by
None — can start immediately.
