# Board: no renderiza cards aunque la query devuelve issues

Created by admin.

## Evidencia

Recorrido visual reproducible con el server operativo en `http://localhost:3333` y viewport 1440×1000:

1. `/#/team/PRB` muestra las cards del team.
2. `/#/board/PRB` ejecuta la query de board con `filter: { team: { eq: <id de PRB> } }` y la respuesta contiene issues (nodes no vacíos).
3. Sin embargo, las diez columnas del board muestran contador `0` y no renderizan ninguna card.

La captura de la comparación quedó en `/tmp/pb-board.png`; la respuesta de red confirma que la query filtrada llega con `pageInfo.hasNextPage: false` y nodes no vacíos.

## Comportamiento esperado

El board debe renderizar las mismas issues que la lista para el mismo team y grupo, incluyendo sus columnas de estado.

## Criterios de aceptación

- [ ] `/#/board/PRB` renderiza las cards recibidas para el team, sin depender del orden de respuestas de queries iniciales.
- [ ] La navegación lista ↔ board conserva el alcance del team.
- [ ] Hay una prueba de regresión para la carga inicial y el cambio de team.
