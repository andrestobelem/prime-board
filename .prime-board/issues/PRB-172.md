# Sistema de íconos monocromo estilo Linear

Created by admin.

La UI usa glifos Unicode como íconos (#, ▦, ◈, ◉, ⚙, ▸/▾, y 'pb' como logo). Se ven pobres y no son consistentes entre sistemas/fuentes.

Queremos un set monocromo fino, 16px, que herede currentColor y funcione en tema oscuro y claro. Un agente (icon-scout) está comparando sets open source (Lucide, Radix Icons, Phosphor, Tabler…) con una hoja de comparación visual en scratchpad/icons/ para decidir entre dependencia npm o vendorizar los SVG en apps/web/src/components/icons.tsx.

Conceptos que la app necesita: workspace/logo, team, lista, board, proyecto, milestone, settings, members, búsqueda, nuevo issue, chevrons, prioridades, estados de issue, label, assignee, target date, archivar, filtro, orden, tema.
