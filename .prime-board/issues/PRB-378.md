# Settings: normalizar la matriz de autorización de Workspace y Team

Created by admin.

## Objetivo
Unificar y documentar los roles Workspace Admin/Member y Team Owner/Member para que la UI, GraphQL, CLI y MCP apliquen la misma matriz de permisos. No duplicar las correcciones de autorización ya cerradas; cubrir los gaps de Settings identificados en PRB-376.

## Contexto
Gap identificado en `docs/research/linear-settings-parity.md` (PRB-376), categoría P0.

## Criterios de aceptación
- Cada mutación de Settings rechaza de forma determinista un rol insuficiente; la UI no ofrece affordances falsas; hay pruebas de API y adapters.
- La implementación debe conservar el modelo local-first, single-tenant y API-first de prime-board.
- Agregar regresiones y evidencia en este issue antes de cerrarlo.
