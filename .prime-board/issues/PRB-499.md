# Seed: el bootstrap adicional omite workspace_id tras PRB-472

Created by admin.

## Hallazgo

La rama `builder/prb-473` (`5e50b80`) crea un Workspace adicional con `seedWorkspace`, pero dos inserciones omiten `workspace_id`:

- `seedTeamWorkflow(db, teamId)` crea `workflow_states` sin contexto.
- La creación de `team_memberships` tampoco envía contexto.

La rama `scout/prb-472` (`58fbcc6`) agrega los triggers `workflow_states_workspace_required_insert` y `team_memberships_workspace_required_insert`, que rechazan `NULL` cuando existen dos Workspaces.

## Comportamiento esperado

Después de integrar PRB-472 y PRB-473, `seedWorkspace` debe crear un segundo Workspace con sus estados y membership sin error.

## Criterios de aceptación

- [ ] El seed de Workflow States envía el Workspace correcto.
- [ ] El seed de Team Membership envía el Workspace correcto.
- [ ] Una prueba ejecuta ambas migraciones y crea dos Workspaces.
- [ ] El seed repetido sigue siendo idempotente y no modifica el primer Workspace.
