# Migrar autenticación, API keys e invitaciones

Created by admin.

## What to build
Migrar autenticación bearer, API keys, scopes, límites por Team, expiración, rotación e invitaciones sin perder seguridad ni trazabilidad.

## Acceptance criteria
- [ ] Hashes existentes autentican y secretos plaintext nunca aparecen en logs ni exportaciones.
- [ ] Revocación, expiración, scopes, límites y rotación conservan su semántica.
- [ ] Invitaciones concurrentes no crean dos actors para un token.
- [ ] Las pruebas de autenticación positiva y negativa pasan en PostgreSQL.
