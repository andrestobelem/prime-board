# CLI: proteger el archivo de credenciales local

Created by admin.

## Hallazgo reproducible

`pb auth login` guarda la API key en `~/.prime-board/cli.json` mediante `Bun.write` sin ajustar permisos. En una cuenta con umask estándar, un archivo nuevo queda `0644`, por lo que otros usuarios locales pueden leer la credencial.

## Evidencia

- `apps/cli/src/config.ts`: `saveConfig` crea `~/.prime-board` y escribe JSON con `Bun.write`, sin `chmod` ni modo privado.
- Reproducción aislada con `HOME=/tmp/pb-mode-test` y `saveConfig({url: "http://example.invalid", apiKey: "fake"})`: `stat` devuelve `0644`.
- La configuración contiene `apiKey` en texto plano y `auth login` la persiste tras validar el servidor.

## Comportamiento esperado

La ruta y el archivo de configuración deben ser privados para el usuario propietario (por ejemplo, directorio `0700` y archivo `0600`), incluyendo archivos preexistentes cuya modalidad sea demasiado permisiva.

## Criterios de aceptación

- Crear y actualizar la configuración con permisos privados.
- Endurecer permisos de una configuración existente al cargar o guardar.
- Agregar una regresión que verifique que no se expone la API key a otros usuarios.
- Documentar la ubicación y la política de permisos sin imprimir la credencial.
