# Búsqueda: incluir comentarios de Issues en full-text

Created by admin.

## Objetivo
Permitir que un agente encuentre contexto histórico buscando también en los comentarios de una Issue.

## Evidencia
- `apps/server/src/db/migrations/0001_init.sql` crea `issues_fts` con `title` y `description` solamente.
- La tabla `comments` no tiene índice full-text ni trigger de sincronización con `issues_fts`.
- `docs/relevamiento-linear.md` clasifica la búsqueda sobre título, descripción y comentarios como imprescindible.
- `docs/specs/mvp.md` dejó comentarios fuera del índice como una limitación histórica.

## Comportamiento esperado
`issues(filter: { search: ... })` encuentra una Issue cuando el término aparece en el título, la descripción o un comentario visible.

## Criterios de aceptación
- [ ] La búsqueda devuelve Issues cuyo comentario contiene el término.
- [ ] Crear, editar y eliminar comentarios mantiene el índice sincronizado.
- [ ] Los resultados no exponen comentarios de Issues archivadas o de otro Workspace.
- [ ] La búsqueda conserva paginación, filtros y orden actuales.
- [ ] Hay pruebas de inserción, actualización, borrado y migración de una base existente.
