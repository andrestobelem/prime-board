# Reviews: paginar la cola web y el contrato GraphQL

Created by admin.

## Objetivo
Permitir recorrer la cola completa de Reviews y no limitarla silenciosamente a 50 elementos.

## Evidencia
- `apps/web/src/views/ReviewsView.tsx` solicita `first: 50` y no recibe `pageInfo`.
- `packages/schema/src/sdl.ts` expone `reviews` como lista sin cursor.
- `apps/server/src/domain/reviews.ts` limita la consulta a 100.

## Criterios de aceptación
- [ ] GraphQL expone una conexión de Reviews con `nodes`, `hasNextPage` y `endCursor`.
- [ ] La UI carga páginas sucesivas y conserva el filtro y el orden.
- [ ] Un error al cargar una página muestra Retry sin perder las páginas anteriores.
- [ ] La API, CLI y MCP documentan el contrato resultante o mantienen una adaptación estable.
- [ ] Hay una prueba con más de 50 Reviews.
