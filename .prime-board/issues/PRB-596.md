# Sincronización de Issue devuelve error después de persistir por archivo de Documents divergente

Created by Micaela.

## Evidencia

El 6 de septiembre de 2026, con el runtime local en `http://127.0.0.1:3333`, una mutación válida de actualización de Issue ejecutada con la identidad de Micaela cambia la Issue pero devuelve el error:

```text
API error: Document archive source replica does not match the existing archive
```

El runtime reporta como réplica `/Users/andrestobelem/ws/at/prime-board/.prime-board`. La réplica contiene `.prime-board/meta/documents.json` vacío y el archivo externo de archivo contiene una fuente `replica` con 5 documentos. La actualización de `PRB-446` quedó aplicada (`In Progress`, assignee `Micaela`) aunque el CLI terminó con código 1.

## Comportamiento esperado

Una mutación no debe devolver error después de persistir el cambio. El sync debe completar de forma atómica o informar una recuperación segura sin dejar la API en estado ambiguo. El archivo de Documents retirados debe validarse con una fuente consistente.

## Criterios de aceptación

- [ ] Una actualización y un comentario válidos terminan con código 0 cuando el archivo de Documents es consistente.
- [ ] Una divergencia no persiste la mutación sin una respuesta de recuperación explícita.
- [ ] El flujo conserva la protección contra pérdida de Documents y no edita `.prime-board/` a mano.
- [ ] Hay una prueba de regresión para el caso de réplica vacía y archivo existente con documentos.
