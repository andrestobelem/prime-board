# question muestra solo números en el selector de opciones

Created by admin.

## Evidencia
La captura `Captura de pantalla 2026-08-19 a la(s) 02.41.36.png` muestra el diálogo de `question` con las opciones completas en el texto superior, pero el selector interactivo inferior renderiza únicamente `1`, `2`, `3`, `4` y `5`.

La extensión usa valores cortos numéricos para evitar truncado de labels largos en selectores antiguos, pero eso hace que la elección sea poco clara y duplica información de forma confusa.

## Comportamiento esperado
El selector debe mostrar labels legibles (o un resumen suficientemente descriptivo), sin perder el mapeo seguro de la opción elegida ni la compatibilidad daemon.

## Criterios de aceptación
- El selector interactivo muestra labels comprensibles para cada opción.
- Las opciones largas no rompen el ancho ni pierden el contenido esencial.
- Se conserva la opción de respuesta libre y el mapeo correcto.
- Hay regresión automatizada.
