# Prime Agent: publicar package y adaptador MCP HTTP para prime-board

Created by admin.

## Objetivo
Integrar las capacidades de prime-board en Prime Agent sin duplicar el contrato de operaciones.

## Alcance
- Crear un package Prime Agent con manifest `pi`, extensión de lifecycle/comandos y skill `prime-board-workflow`.
- Añadir MCP Streamable HTTP local reutilizando los handlers existentes, o documentar una skill GraphQL equivalente si se descarta MCP HTTP.
- Mantener GraphQL como autoridad, bearer auth, identidad de agente por proyecto y storage 0600.
- Probar instalación global/proyecto, `/reload`, kernel Python, health-check, CLI y UI.

## Criterios de aceptación
- [ ] `prime-agent package install ... --local` descubre extensión y skills en una instalación limpia.
- [ ] La extensión resuelve el repositorio desde `ctx.cwd`, arranca/verifica el runtime y no duplica procesos.
- [ ] El modelo puede listar/crear/actualizar/comentar issues con cobertura MCP/GraphQL sin shell arbitrario.
- [ ] MCP HTTP/skill maneja auth, errores, reconexión y cierre sin secretos en settings o `.prime-board`.
- [ ] Se validan dos proyectos y sesiones concurrentes; multi-Workspace continúa deshabilitado.
