# Activity: registrar cambios de cycle en operaciones masivas

Created by admin.

## Origen

Implementación de PRB-239 (Activity para cambios de `cycleId` y `sortOrder`).

## Evidencia

Además de `issueUpdate`, `apps/server/src/domain/cycles.ts` modifica `issues.cycle_id` directamente en dos operaciones:

- `deleteCycle` desasigna los issues del cycle con `UPDATE issues SET cycle_id = NULL`.
- `carryOverCycle` mueve issues del cycle origen al destino con `UPDATE issues SET cycle_id = ?2`.

Ninguna operación registra `cycle_changed`, por lo que el historial append-only y el log exportable omiten cambios visibles en el issue.

## Criterios de aceptación

- [ ] Las operaciones de borrar un cycle y hacer carry-over registran un Activity `cycle_changed` por cada issue afectado, con actor, valor anterior y nuevo.
- [ ] Los eventos se exportan/importan usando referencias estables de cycle.
- [ ] Tests verifican actor, cardinalidad, valores y round-trip.
- [ ] La operación conserva su comportamiento actual de desasignación/movimiento.
