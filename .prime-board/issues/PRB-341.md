# Inbox: rechazar cursores inválidos en la paginación

Created by admin.

## Hallazgo reproducible

`listInboxActivityPage` reinicia desde la primera página cuando `after` está malformado o no pertenece al conjunto actual. A diferencia de `issues`, la API no devuelve `VALIDATION_FAILED`; el cliente puede repetir la primera página sin detectar el cursor inválido.

## Comportamiento esperado

Un cursor inválido, truncado o ajeno a la consulta debe producir `VALIDATION_FAILED` y no reiniciar silenciosamente la conexión.

## Criterios de aceptación

- Rechazar cursores malformados.
- Rechazar cursores que no correspondan a una entrada visible del inbox.
- Mantener la paginación válida y agregar regresiones GraphQL.
