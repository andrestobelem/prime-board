# Workspace: permitir renombrar el espacio

Created by admin.

## Objetivo

Permitir renombrar el Workspace desde las superficies oficiales de prime-board para no depender de cambios directos en SQLite.

## Contexto

El Workspace actual se llama `andrestobelem`, pero el Team histórico `AT` tiene el mismo nombre. Hoy `Workspace` solo se puede consultar: no existe `workspaceUpdate` en GraphQL ni comando equivalente en CLI, MCP o UI.

## Alcance

- Agregar una mutación GraphQL `workspaceUpdate` para cambiar el nombre.
- Autorizar la operación únicamente a Workspace Admins.
- Exponerla en CLI, MCP y UI con validación y confirmación adecuadas.
- Persistir el nuevo nombre en exportaciones y rebuilds sin modificar `urlKey` ni identificadores.
- Documentar la diferencia entre el nombre del Workspace y los nombres/keys de Teams.

## Criterios de aceptación

- Un Workspace Admin puede cambiar el nombre y cualquier otro actor recibe un error de autorización.
- El nombre nuevo se refleja en API, CLI, MCP y UI después de persistirlo.
- `urlKey`, Team keys, Issues y referencias históricas no cambian.
- Export y rebuild conservan el nombre actualizado.
- Hay regresiones para autorización, persistencia y superficies de cliente.
