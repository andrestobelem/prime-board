# Web: ordenar la jerarquía del panel Workspace administration

Created by admin.

## Objetivo
Ordenar la jerarquía visual de la pantalla `Workspace administration`.

## Evidencia
La captura `Captura de pantalla 2026-08-24 a la(s) 01.44.01.png` muestra un panel anidado con el mismo borde y peso visual que su contenedor. El formulario de `Workspace name` queda pegado al borde izquierdo, mientras el encabezado tiene demasiado espacio vertical.

## Criterios de aceptación
- El panel principal y sus subsecciones tienen una jerarquía visual clara.
- El formulario de Workspace tiene padding, alineación y separación consistentes.
- El nombre, el campo editable y el `URL key` se leen como un grupo.
- El layout conserva foco de teclado, accesibilidad y comportamiento responsive.
- Hay una validación reproducible del layout.
