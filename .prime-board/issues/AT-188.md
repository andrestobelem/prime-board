# Construir dry-run y reconciliación de la migración Linear → prime-board

Created by Andrés Tobelem.

## Objetivo

Validar la migración antes de hacer escrituras definitivas y demostrar que el resultado es completo.

## Validaciones mínimas

Conteo de issues, proyectos, milestones, actores, labels y comentarios; identificadores; estados; prioridades; asignaciones; padres; relaciones; archivados; y hashes o comparaciones de contenido.

## Aceptación

* El dry-run produce un plan y un reporte legible para humanos y JSON para agentes.
* Una segunda ejecución no genera cambios.
* Las discrepancias se clasifican como error, conflicto o pérdida aceptada.
* La migración se aborta si quedan errores o conflictos no resueltos.
