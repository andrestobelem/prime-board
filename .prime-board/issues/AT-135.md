# GraphQL: labels de workspace y de team

Mutation `labelCreate` (con `teamId` opcional: NULL = workspace), query `labels`, y asociación N:M a issues vía `issueUpdate` (set/add/remove).

**Entregable:** etiquetar y filtrar issues por label. Spec de referencia: [`docs/specs/mvp.md`](<https://github.com/andrestobelem/prime-board/blob/main/docs/specs/mvp.md>).
