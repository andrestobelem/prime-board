# Permitir modo local sin pedir API key

Created by admin.

## Evidencia
La interfaz web de una instancia local pedía una API key aunque el servidor y la interfaz se ejecutaban en el mismo equipo. La instancia local escuchaba en todas las interfaces (`*:3333`).

## Comportamiento esperado
Una instancia explícitamente local debe permitir el uso de la interfaz sin pegar una API key y debe quedar limitada a loopback. El modo normal con API key debe conservar su comportamiento.

## Criterios de aceptación
- `PRIME_BOARD_AUTH_MODE=local` acepta consultas y mutaciones sin `Authorization`.
- El modo local escucha solo en `127.0.0.1`.
- La interfaz no muestra el formulario `Save & connect` en modo local.
- El modo `api-key` sigue rechazando solicitudes sin key.
- La documentación explica el riesgo de dar acceso completo al modo local.
