# UI: descartar respuestas obsoletas de paginación en Team, Board y Project

Created by admin.

## Hallazgo reproducible

Las funciones `loadMore` de `TeamView`, `BoardView` y `ProjectView` concatenan una respuesta in-flight sin verificar que el filtro, la ruta, el orden o la consulta actual sigan vigentes. Si el usuario cambia de vista mientras carga una página, issues de la consulta anterior quedan mezclados en la vista nueva.

## Comportamiento esperado

Una respuesta de paginación solo puede actualizar el estado de la consulta que la originó. Cambios de ruta/filtro/orden deben invalidar respuestas pendientes y deduplicar entidades.

## Criterios de aceptación

- Cambiar filtro/ruta durante `loadMore` no mezcla issues de consultas.
- Las páginas sucesivas no duplican issues.
- Agregar regresiones de generación/cancelación para las tres vistas.
