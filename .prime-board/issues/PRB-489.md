# QA: matriz de aislamiento para CLI, MCP y UI

Created by admin.

## Objetivo
Verificar que todos los clientes usan el Workspace efectivo y limpian su estado.

## Criterios de aceptación
- CLI, MCP y UI descubren y seleccionan solo Workspaces concedidos.
- Cambio A↔B no conserva IDs, cache, Favorites, Inbox, Views ni permisos.
- Se prueban perfiles legacy, bearer, referencias homónimas, deep-links y Actor suspendido.
- Los contratos JSON, MCP y UI/e2e producen un reporte común de regresiones.

## Seam de validación
Suites de `apps/cli`, `apps/mcp`, `apps/web` y fixtures con uno/dos Workspaces.

## Dependencias
Requiere PRB-415, PRB-418 y PRB-419.
