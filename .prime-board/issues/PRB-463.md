# Smoke de instalación y aislamiento en Prime Agent

Created by admin.

## What to build
Una prueba end-to-end de instalación que verifique el package, runtime, MCP/skill, CLI, UI y dos Repository Replicas sin habilitar multi-Workspace.

## Acceptance criteria
- [ ] Instalación global y local, `/reload` y sesión nueva completan el flujo.
- [ ] Dos proyectos y sesiones concurrentes conservan procesos, DBs y réplicas aislados.
- [ ] Health, GraphQL/MCP, CLI y UI funcionan en el artefacto final.
- [ ] No aparecen secretos en settings, logs ni `.prime-board/`.
- [ ] No existe selector multi-Workspace ni se acepta un `workspaceId` arbitrario.

## Test seam
Instalación limpia + sesión Prime Agent + dos proyectos + API/MCP/CLI/UI.
