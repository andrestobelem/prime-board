# UI: invalidar páginas extra después de refetch de la página base

Created by admin.

## Hallazgo reproducible

MyIssues, Cycle y SavedView limpian entradas extra solo cuando cambia el filtro. Tras una mutación, el refetch de la primera página deja `extraIssues` antiguos y `appendUniqueById` los conserva en pantalla.

## Comportamiento esperado

Un refetch de la página base debe invalidar las páginas extra o actualizar sus entidades, evitando mostrar issues archivadas o con metadata obsoleta.

## Criterios de aceptación

- Limpiar extras al recibir nueva página base.
- Mantener paginación disponible con pageInfo nuevo.
- Regresión.
