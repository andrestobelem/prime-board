# Validación de ciclos en relaciones de bloqueo

## Parent

AT-174 — Relaciones entre issues (blocking / blocked-by)

## What to build

Crear una relación de bloqueo que cierre un ciclo falla en vez de dejar el grafo en un estado sin solución. Sin esto, el frontier de `/wayfinder` puede quedar vacío para siempre.

## Acceptance criteria

- [ ] Ciclo directo (A bloqueado por B, B bloqueado por A) → `VALIDATION_FAILED`
- [ ] Ciclo transitivo (A→B→C→A) → `VALIDATION_FAILED`
- [ ] El mensaje de error nombra los issues involucrados
- [ ] Tests con ciclo directo y transitivo
