# Web: conservar el foco de los inputs durante las búsquedas

Created by admin.

## Objetivo
Evitar que los campos de búsqueda y otros inputs pierdan el foco al escribir.

## Evidencia
La captura `Captura de pantalla 2026-08-24 a la(s) 02.18.19.png` muestra la búsqueda de Documents. El usuario informa que al escribir un carácter el campo pierde el foco y que el problema aparece en más de un lugar.

## Causa observada
Las vistas que usan `useQuery` devuelven `Loading…` cuando cambia una variable de consulta y todavía no hay datos. El formulario se desmonta durante el refetch; al volver a montarse, el input pierde el foco.

## Criterios de aceptación
- Escribir en una búsqueda no desmonta el campo ni pierde el foco.
- El comportamiento se conserva durante el refetch y ante respuestas lentas.
- Se cubre el patrón compartido por `useQuery` con una regresión reproducible.
- Las vistas conservan estados de carga, error y retry.
