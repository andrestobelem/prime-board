# Importar comentarios, actividad y relaciones de issues

Created by Andrés Tobelem.

## Objetivo

Migrar el contexto colaborativo que permite a un agente retomar un issue sin volver a Linear.

## Alcance

Comentarios con autor y fecha, historial de estados/cambios disponible, jerarquía de padres, relaciones `blocks`, `blocked-by`, `related` y `duplicate-of`, y enlaces internos entre issues.

## Aceptación

* Los comentarios quedan consultables desde la API y el repo.
* Se preservan autores y timestamps originales cuando existen.
* Las relaciones se reconstruyen sin duplicados ni ciclos inválidos.
* Toda pérdida por threads, comentarios inline o actividad no disponible queda reportada.
