# Migrar filtros, cursores y full-text search

Created by admin.

## What to build
Reemplazar la sintaxis de filtros SQLite y FTS5 por consultas PostgreSQL equivalentes, seguras y compatibles con el contrato público.

## Acceptance criteria
- [ ] Predicados `and`/`or`, comparadores, labels, estados y `unblocked` conservan resultados.
- [ ] Prefijos, frases, mayúsculas, acentos, caracteres especiales y entradas inválidas conservan el contrato probado.
- [ ] Las consultas usan parámetros y no permiten inyección mediante búsqueda o filtros.
- [ ] El índice de búsqueda se reconstruye al importar datos.
